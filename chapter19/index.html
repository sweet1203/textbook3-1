    최종 미션 — 나만의 사회문제에 알고리즘 적용하기¶

    🎯 이 장에서 배우는 것¶

    • 스스로 선택한 사회문제에 문제 분해 → 추상화 → 모델링 → 알고리즘 선택의 전 과정을 적용할 수 있다
    • 선택한 알고리즘이 왜 해당 문제에 적합한지 근거를 들어 설명할 수 있다
    • 알고리즘 효율의 가치와 사회적 영향력을 인식하고 탐구하는 태도를 가질 수 있다
    • 이 단원에서 배운 내용을 종합하여 실제 문제 해결에 적용할 수 있다

    💡 왜 이걸 배우나요?¶

    "진짜 실력은 스스로 문제를 찾고 해결할 때 드러납니다."

    지금까지 여러분은 응급의료, 재난구조, 환경, 스마트시티, 복지, 의료 등 다양한 사회문제에 알고리즘을 적용하는 방법을 배웠습니다. 하지만 이 모든 문제는 선생님이 제시한 것이었죠.

    이번 최종 미션에서는 여러분이 직접 관심 있는 사회문제를 선택합니다. 그리고 지금까지 배운 모든 과정—문제 분해, 추상화, 모델링, 알고리즘 선택—을 처음부터 끝까지 스스로 수행합니다.

    flowchart LR subgraph 지금까지 A[선생님이 문제 제시] --> B[학생이 해결] end subgraph 이번 미션 C[학생이 문제 발견] --> D[학생이 해결] end 지금까지 --> 이번 미션 style 이번 미션 fill:#e8f5e9

    왜 이것이 중요할까요?

    실제 세상에서는 누구도 "이 문제를 이 알고리즘으로 풀어보세요"라고 말해주지 않습니다. 프로그래머, 데이터 과학자, 정책 설계자 모두 스스로 문제를 정의하고 해결 방법을 찾아야 합니다. 이번 미션은 그 첫걸음입니다.

    💭 생각해보기: 여러분 주변에서 "이건 좀 불편한데?", "이게 왜 이렇게 비효율적이지?"라고 느낀 적이 있나요? 그 순간이 바로 문제 발견의 시작입니다.

    📚 핵심 개념¶

    개념 1: 문제 해결의 4단계 프로세스¶

    🎭 비유로 시작하기

    의사가 환자를 진료하는 과정을 떠올려보세요.

    flowchart LR A[증상 파악] --> B[검사 및 분석] B --> C[진단명 결정] C --> D[치료법 선택]

    환자가 "배가 아파요"라고 말하면, 의사는 바로 약을 처방하지 않습니다. 어디가 어떻게 아픈지 증상을 파악하고, 필요하면 검사를 하고, 진단명을 내린 후에야 적절한 치료법을 선택합니다.

    알고리즘으로 사회문제를 해결하는 것도 똑같습니다.

    📖 정확한 정의

    문제 해결의 4단계 프로세스는 복잡한 문제를 체계적으로 분석하고 해결하기 위한 절차입니다.

    flowchart TD subgraph STEP1[1단계: 문제 분해] A1[큰 문제를 작은 문제로 나누기] end subgraph STEP2[2단계: 추상화] A2[핵심 요소만 추출하기] end subgraph STEP3[3단계: 모델링] A3[요소 간 관계를 구조화하기] end subgraph STEP4[4단계: 알고리즘 선택] A4[문제에 맞는 알고리즘 결정하기] end STEP1 --> STEP2 --> STEP3 --> STEP4

    ✅ 예시로 확인

    "학교 급식 대기 시간이 너무 길다"라는 문제가 있다고 가정해봅시다.

    1단계 - 문제 분해 - 학생들이 줄을 서는 방식의 문제 - 배식 속도의 문제 - 메뉴 선택 시간의 문제 - 결제 시간의 문제

    2단계 - 추상화 - 핵심 요소: 학생 수, 배식구 개수, 학생별 배식 시간 - 제거할 요소: 메뉴의 맛, 식당 인테리어

    3단계 - 모델링 - 학생 = 처리해야 할 데이터 - 배식구 = 처리 장치 - 대기열 = 정렬이 필요한 리스트

    4단계 - 알고리즘 선택 - 대기 시간 최소화 → 우선순위 기반 정렬(빨리 먹고 갈 학생 먼저)

    개념 2: 알고리즘 선택의 기준¶

    🎭 비유로 시작하기

    여행을 갈 때 교통수단을 어떻게 선택하나요?

    • 서울에서 부산: 비행기? KTX? 자가용?
    • 집에서 편의점: 걸어서? 자전거?

    거리, 시간, 비용, 편의성 등 여러 기준을 고려해서 선택하죠. 알고리즘 선택도 마찬가지입니다.

    📖 정확한 정의

    알고리즘을 선택할 때는 다음 기준들을 고려해야 합니다.

    기준 1: 데이터의 특성 - 데이터가 이미 정렬되어 있는가? - 데이터의 양이 얼마나 되는가? - 데이터가 어떤 구조로 저장되어 있는가?

    기준 2: 문제의 목적 - 데이터를 순서대로 정리해야 하는가? → 정렬 알고리즘 - 특정 데이터를 찾아야 하는가? → 탐색 알고리즘 - 최적의 경로나 선택을 찾아야 하는가? → 탐색 알고리즘

    기준 3: 효율성 요구 - 빠른 응답이 필요한가? (실시간 시스템) - 메모리 사용량에 제한이 있는가?

    flowchart TD Q1{데이터를 순서대로<br/>정리해야 하나요?} Q2{특정 값을<br/>찾아야 하나요?} Q3{데이터가 이미<br/>정렬되어 있나요?} A1[정렬 알고리즘 사용] A2[순차 탐색 사용] A3[이진 탐색 사용] Q1 -->|예| A1 Q1 -->|아니오| Q2 Q2 -->|예| Q3 Q2 -->|아니오| MORE[다른 알고리즘 고려] Q3 -->|예| A3 Q3 -->|아니오| A2

    ✅ 예시로 확인

    상황 A: 100명의 학생 성적을 높은 순으로 정리하고 싶다 - 목적: 순서대로 정리 → 정렬 알고리즘 - 데이터 양: 100개(적음) → 버블 정렬도 충분

    상황 B: 10만 명의 회원 중 특정 회원을 찾고 싶다 - 목적: 특정 값 찾기 → 탐색 알고리즘 - 데이터 양: 10만 개(많음) - 데이터가 정렬되어 있다면 → 이진 탐색 - 정렬되어 있지 않다면 → 순차 탐색 또는 먼저 정렬 후 이진 탐색

    개념 3: 알고리즘의 사회적 영향력¶

    🎭 비유로 시작하기

    작은 나비의 날갯짓이 지구 반대편에 태풍을 일으킬 수 있다는 "나비 효과"를 들어보셨나요? 알고리즘도 마찬가지입니다. 단 몇 줄의 코드가 수백만 명의 삶에 영향을 미칠 수 있습니다.

    📖 정확한 정의

    알고리즘의 사회적 영향력이란, 알고리즘이 개인의 선택, 사회 시스템, 심지어 민주주의와 경제에까지 미치는 광범위한 영향을 의미합니다.

    flowchart TD ALG[알고리즘] ALG --> POS[긍정적 영향] ALG --> NEG[부정적 영향] POS --> P1[응급환자 생명 구조] POS --> P2[교통 체증 감소] POS --> P3[에너지 절약] NEG --> N1[개인정보 침해 가능성] NEG --> N2[편향된 의사결정] NEG --> N3[일자리 대체]

    ✅ 예시로 확인

    긍정적 사례: 이 단원에서 배운 것들 - 응급환자 분류 알고리즘: 골든타임 내 치료율 향상 - 재난 대피 경로 탐색: 대피 시간 단축으로 인명 피해 감소 - 스마트 신호등: 교통 흐름 개선으로 탄소 배출 감소

    주의가 필요한 사례 - 채용 알고리즘이 특정 성별이나 인종에 편향된 결과를 보인 사례 - SNS 추천 알고리즘이 가짜 뉴스를 확산시킨 사례

    💭 생각해보기: 알고리즘을 설계할 때 "이것이 사람들에게 어떤 영향을 미칠까?"를 항상 고민해야 하는 이유가 여기에 있습니다.

    개념 4: 자기 평가와 성찰¶

    🎭 비유로 시작하기

    운동선수들은 경기가 끝난 후 영상을 돌려보며 자신의 플레이를 분석합니다. 잘한 점은 유지하고, 부족한 점은 보완하기 위해서죠. 이것이 바로 성찰입니다.

    📖 정확한 정의

    자기 평가와 성찰은 자신의 학습 과정과 결과를 객관적으로 돌아보고, 개선점을 찾아 다음 학습에 적용하는 메타인지 활동입니다.

    성찰의 3가지 질문: - 무엇을 배웠는가? (What) - 어떻게 배웠는가? (How) - 왜 그것이 중요한가? (Why)

    ✅ 예시로 확인

    "나는 이진 탐색을 배웠다"라고 끝내는 것이 아니라...

    • What: 정렬된 데이터에서 중간값을 기준으로 범위를 절반씩 줄여가며 찾는 방법을 배웠다
    • How: 사전에서 단어를 찾는 비유로 이해했고, 코드로 직접 구현해보았다
    • Why: 데이터가 많을 때 순차 탐색보다 훨씬 빠르기 때문에, 실제 검색 시스템에서 필수적이다

    🔨 따라하기: 나만의 사회문제 해결 프로젝트¶

    Step 1: 사회문제 선택하기¶

    먼저 여러분이 해결하고 싶은 사회문제를 선택합니다.

    문제 선택 가이드

    다음 분야에서 관심 있는 주제를 떠올려보세요:

    Step 5: 알고리즘 선택하기¶

    문제 유형에 맞는 알고리즘을 선택하고, 그 이유를 설명합니다.

    알고리즘 선택 의사결정

    flowchart TD Q1{내 문제의 핵심은<br/>무엇인가?} Q1 -->|데이터 정리| SORT[정렬 알고리즘] Q1 -->|데이터 찾기| SEARCH[탐색 알고리즘] SORT --> S1{데이터 양이<br/>많은가?} S1 -->|적음| BUBBLE[버블/삽입 정렬] S1 -->|많음| QUICK[퀵 정렬] SEARCH --> S2{데이터가<br/>정렬되어 있는가?} S2 -->|예| BINARY[이진 탐색] S2 -->|아니오| SEQ[순차 탐색]

    실습 예시: 도서관 좌석 배정

    이 문제에서는 두 가지 알고리즘이 필요합니다.

    1. 빈 좌석 찾기 → 순차 탐색 - 이유: 좌석 상태가 정렬되어 있지 않으므로 - 좌석을 하나씩 확인하며 "empty" 상태인 것을 찾음

    2. 이용 시간이 긴 순서로 정렬 → 삽입 정렬 - 이유: 데이터 양이 적고(50석), 대부분 정렬된 상태일 가능성이 높음 - 오래 사용한 학생에게 알림을 보내기 위해

    # 알고리즘 1: 빈 좌석 찾기 (순차 탐색)
def find_empty_seat(seats):
    """빈 좌석을 찾아 반환합니다."""
    for seat in seats:
        if seat.status == "empty":
            return seat
    return None  # 빈 좌석 없음

# 알고리즘 2: 이용 시간 순 정렬 (삽입 정렬)
def sort_by_usage_time(occupied_seats):
    """이용 시간이 긴 순서로 정렬합니다."""
    sorted_list = []
    for seat in occupied_seats:
        # 적절한 위치에 삽입
        inserted = False
        for i in range(len(sorted_list)):
            if seat.start_time < sorted_list[i].start_time:
                sorted_list.insert(i, seat)
                inserted = True
                break
        if not inserted:
            sorted_list.append(seat)
    return sorted_list

    import random

class Seat:
    """좌석 클래스"""
    def __init__(self, seat_id):
        self.seat_id = seat_id
        self.status = "empty"
        self.student_id = None
        self.start_time = None

    def occupy(self, student_id, start_time):
        """좌석 사용 시작"""
        self.status = "occupied"
        self.student_id = student_id
        self.start_time = start_time

    def release(self):
        """좌석 반납"""
        self.status = "empty"
        self.student_id = None
        self.start_time = None

class LibrarySystem:
    """도서관 좌석 관리 시스템"""
    def __init__(self, num_seats):
        self.seats = [Seat(i) for i in range(1, num_seats + 1)]

    def find_empty_seat(self):
        """빈 좌석 찾기 - 순차 탐색"""
        search_count = 0
        for seat in self.seats:
            search_count += 1
            if seat.status == "empty":
                print(f"탐색 횟수: {search_count}회")
                return seat
        print(f"탐색 횟수: {search_count}회 - 빈 좌석 없음")
        return None

    def get_long_users(self, current_time, limit_hours=3):
        """오래 사용한 학생 목록 - 정렬 후 필터링"""
        occupied = [s for s in self.seats if s.status == "occupied"]

        # 삽입 정렬로 이용 시간 순 정렬
        sorted_seats = []
        for seat in occupied:
            inserted = False
            for i in range(len(sorted_seats)):
                if seat.start_time < sorted_seats[i].start_time:
                    sorted_seats.insert(i, seat)
                    inserted = True
                    break
            if not inserted:
                sorted_seats.append(seat)

        # 제한 시간 초과 학생 필터링
        long_users = []
        for seat in sorted_seats:
            usage_time = current_time - seat.start_time
            if usage_time >= limit_hours:
                long_users.append((seat, usage_time))

        return long_users

    def show_status(self):
        """현재 좌석 현황 출력"""
        empty_count = sum(1 for s in self.seats if s.status == "empty")
        occupied_count = len(self.seats) - empty_count
        print(f"\n📊 좌석 현황: 사용 중 {occupied_count}석 / 비어있음 {empty_count}석")

    아래는 여러분이 자신만의 문제에 적용할 수 있는 템플릿 코드입니다.

    """
나만의 사회문제 해결 프로젝트 템플릿
===================================
문제: [여기에 문제 작성]

날짜: [날짜]

# ========== 1단계: 데이터 모델 정의 ==========
class DataItem:
    """
    문제의 핵심 데이터를 표현하는 클래스
    (자신의 문제에 맞게 수정하세요)
    """
    def __init__(self, item_id, value):
        self.item_id = item_id
        self.value = value
        # 필요한 속성 추가

    def __str__(self):
        return f"ID: {self.item_id}, 값: {self.value}"


# ========== 2단계: 알고리즘 함수 정의 ==========

def sequential_search(data_list, target):
    """
    순차 탐색: 처음부터 끝까지 하나씩 확인
    - 정렬되지 않은 데이터에 사용
    """
    for i, item in enumerate(data_list):
        if item.value == target:
            return i, item
    return -1, None


def binary_search(sorted_list, target):
    """
    이진 탐색: 중간값을 기준으로 범위를 절반씩 줄임
    - 반드시 정렬된 데이터에만 사용!
    """
    low, high = 0, len(sorted_list) - 1

    while low <= high:
        mid = (low + high) // 2
        if sorted_list[mid].value == target:
            return mid, sorted_list[mid]
        elif sorted_list[mid].value < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1, None


def bubble_sort(data_list, key_func, reverse=False):
    """
    버블 정렬: 인접한 요소를 비교하며 교환
    - key_func: 정렬 기준을 반환하는 함수
    - reverse: True면 내림차순
    """
    result = data_list.copy()
    n = len(result)

    for i in range(n - 1):
        for j in range(n - 1 - i):
            should_swap = key_func(result[j]) > key_func(result[j + 1])
            if reverse:
                should_swap = not should_swap
            if should_swap:
                result[j], result[j + 1] = result[j + 1], result[j]

    return result


def insertion_sort(data_list, key_func, reverse=False):
    """
    삽입 정렬: 정렬된 부분에 적절한 위치로 삽입
    - 대부분 정렬된 데이터에 효율적
    """
    result = data_list.copy()

    for i in range(1, len(result)):
        key_item = result[i]
        j = i - 1

        while j >= 0:
            should_move = key_func(result[j]) > key_func(key_item)
            if reverse:
                should_move = key_func(result[j]) < key_func(key_item)

            if should_move:
                result[j + 1] = result[j]
                j -= 1
            else:
                break

        result[j + 1] = key_item

    return result


# ========== 3단계: 메인 시스템 클래스 ==========
class ProblemSolver:
    """
    문제 해결 시스템
    (자신의 문제에 맞게 메서드를 수정/추가하세요)
    """
    def __init__(self):
        self.data = []

    def add_data(self, item):
        """데이터 추가"""
        self.data.append(item)

    def find_by_value(self, target):
        """특정 값을 가진 데이터 찾기"""
        return sequential_search(self.data, target)

    def sort_data(self, key="value", reverse=False):
        """데이터 정렬"""
        key_func = lambda x: getattr(x, key)
        return insertion_sort(self.data, key_func, reverse)

    def show_all(self):
        """모든 데이터 출력"""
        print(f"\n총 {len(self.data)}개의 데이터:")
        for item in self.data:
            print(f"  - {item}")

    실수 2: 알고리즘 선택 이유를 설명하지 못한다¶

    ❌ 잘못된 예 

    "정렬이 필요해서 버블 정렬을 사용했다"

    ✅ 올바른 예

    실수 3: 이진 탐색을 정렬되지 않은 데이터에 적용한다¶

    ❌ 잘못된 코드

# 이진 탐색 시도 → 잘못된 결과!

    ✅ 올바른 코드 

    data = [50, 20, 80, 30, 60]

    도전 과제 1: 다른 알고리즘으로 해결해보기¶

    같은 문제를 다른 알고리즘으로 해결하고 성능을 비교해보세요.

    import time

def measure_time(algorithm_func, data):
    """알고리즘 수행 시간 측정"""
    start = time.time()
    result = algorithm_func(data)
    end = time.time()
    return result, end - start
