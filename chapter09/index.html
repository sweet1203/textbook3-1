    ♻️ 거품처럼 떠오르는 정렬 — 버블 정렬 완전 정복¶

    Part 3: 정렬 알고리즘 — 데이터를 순서대로 정리하는 방법

    🎯 이 장에서 배우는 것¶

    • 버블 정렬의 작동 원리(인접 요소 비교·교환)를 단계별로 설명할 수 있다
    • 5개 이상의 데이터에 대해 버블 정렬의 전체 과정을 손으로 직접 수행할 수 있다
    • 버블 정렬의 수행 시간이 O(n²)인 이유를 간단히 설명할 수 있다
    • 파이썬으로 버블 정렬 알고리즘을 구현할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    재활용 센터에서 폐기물을 처리하려고 합니다. 무게가 [10, 6, 2, 4, 3]kg인 5개의 폐기물이 있는데, 가벼운 것부터 먼저 처리해야 효율적입니다. 어떻게 정리하면 좋을까요?

    여러분이 책꽂이의 책을 키 순서대로 정리하거나, 시험 점수를 높은 순서대로 나열해 본 경험이 있을 겁니다. 이렇게 데이터를 특정 기준에 따라 순서대로 재배열하는 것을 정렬(Sorting)이라고 합니다.

    컴퓨터가 데이터를 정렬하는 방법은 여러 가지가 있는데, 오늘 배울 버블 정렬은 가장 직관적이고 이해하기 쉬운 정렬 알고리즘입니다. 마치 탄산음료의 거품이 아래에서 위로 떠오르듯, 큰 값이 한 칸씩 뒤로 이동하는 모습에서 이름이 붙었습니다.

    📚 핵심 개념¶

    개념 1: 정렬이란 무엇인가?¶

    1. 비유로 시작

    운동회에서 키 순서대로 줄을 서야 한다고 상상해 보세요. 선생님이 "옆 사람과 비교해서 키가 더 작은 사람이 앞으로 가세요!"라고 말합니다. 이 과정을 반복하면 결국 모든 학생이 키 순서대로 정렬됩니다.

    2. 정확한 정의

    정렬(Sorting): 나열된 데이터를 특정 기준(키, Key)에 따라 오름차순 또는 내림차순으로 재배열하는 작업

    3. 예시로 확인

    정렬 전: [10, 6, 2, 4, 3]
오름차순 정렬 후: [2, 3, 4, 6, 10]  ← 작은 것부터
내림차순 정렬 후: [10, 6, 4, 3, 2]  ← 큰 것부터

    개념 2: 버블 정렬의 작동 원리¶

    1. 비유로 시작

    탄산음료 컵을 생각해 보세요. 바닥에서 생긴 거품이 위로 올라가면서 점점 커지죠? 버블 정렬도 비슷합니다. 큰 값이 거품처럼 뒤쪽으로 떠올라 자기 자리를 찾아갑니다.

    2. 정확한 정의

    버블 정렬(Bubble Sort): 리스트의 앞에서부터 인접한 두 요소를 비교하여 순서가 잘못되었으면 위치를 교환하는 과정을 반복하는 정렬 알고리즘

    3. 핵심 규칙

    • 비교: 바로 옆에 있는 두 요소만 비교한다
    • 교환: 앞의 값이 뒤의 값보다 크면 자리를 바꾼다
    • 반복: 리스트 끝까지 가면 처음부터 다시 시작한다
    • 종료: 더 이상 교환이 필요 없으면 정렬 완료
    flowchart LR subgraph 비교 A["앞 요소"] --> C{앞 > 뒤?} B["뒤 요소"] --> C end C -->|Yes| D["교환!"] C -->|No| E["그대로"] D --> F["다음 쌍으로 이동"] E --> F

    개념 3: 버블 정렬의 단계별 과정¶

    [10, 6, 2, 4, 3]을 오름차순으로 정렬해 봅시다.

    📍 1단계 (첫 번째 반복)

    flowchart LR subgraph "1-1: 10과 6 비교" A1["[🔴10, 🔴6, 2, 4, 3]"] -->|"10>6 교환!"| B1["[6, 10, 2, 4, 3]"] end
    flowchart LR subgraph "1-2: 10과 2 비교" A2["[6, 🔴10, 🔴2, 4, 3]"] -->|"10>2 교환!"| B2["[6, 2, 10, 4, 3]"] end
    flowchart LR subgraph "1-3: 10과 4 비교" A3["[6, 2, 🔴10, 🔴4, 3]"] -->|"10>4 교환!"| B3["[6, 2, 4, 10, 3]"] end
    flowchart LR subgraph "1-4: 10과 3 비교" A4["[6, 2, 4, 🔴10, 🔴3]"] -->|"10>3 교환!"| B4["[6, 2, 4, 3, ✅10]"] end

    1단계 결과: [6, 2, 4, 3, ✅10] — 가장 큰 값 10이 맨 뒤에 고정!

    📍 2단계 (두 번째 반복)

    이제 마지막 10은 제외하고 나머지 4개만 비교합니다.

    • 6과 2 비교 → 교환 → [2, 6, 4, 3, 10]
    • 6과 4 비교 → 교환 → [2, 4, 6, 3, 10]
    • 6과 3 비교 → 교환 → [2, 4, 3, ✅6, ✅10]

    2단계 결과: 두 번째로 큰 값 6이 고정!

    📍 3단계

    • 2와 4 비교 → 그대로
    • 4와 3 비교 → 교환 → [2, 3, ✅4, ✅6, ✅10]

    📍 4단계

    • 2와 3 비교 → 그대로 → [✅2, ✅3, ✅4, ✅6, ✅10]

    최종 결과: [2, 3, 4, 6, 10] 🎉

    개념 4: 버블 정렬의 성능 — O(n²)¶

    1. 비유로 시작

    교실에서 30명이 키 순서대로 줄을 서려면 옆 사람과 비교하는 횟수가 얼마나 될까요? 첫 번째 줄서기에 29번, 두 번째에 28번... 거의 모든 학생이 여러 번 비교해야 합니다.

    2. 비교 횟수 계산

    데이터가 5개일 때: - 1단계: 4번 비교 - 2단계: 3번 비교 - 3단계: 2번 비교 - 4단계: 1번 비교 - 총 비교 횟수: 4 + 3 + 2 + 1 = 10번

    데이터가 n개일 때: - 총 비교 횟수: (n-1) + (n-2) + ... + 1 = n(n-1)/2

    3. 빅오 표기법

    n(n-1)/2를 전개하면 (n² - n)/2입니다. n이 매우 커지면 n²이 지배적이므로:

    버블 정렬의 시간 복잡도: O(n²)

    graph LR subgraph "데이터 크기에 따른 비교 횟수" A["n=10<br/>45번"] --> B["n=100<br/>4,950번"] B --> C["n=1000<br/>499,500번"] end

    알아보기 💡

    O(n²)은 데이터가 2배가 되면 처리 시간이 약 4배가 된다는 의미입니다. 따라서 버블 정렬은 데이터가 적을 때는 괜찮지만, 수만 개 이상의 대용량 데이터에는 적합하지 않습니다.

    🔨 따라하기¶

    Step 1: 기본 구조 이해하기¶

    버블 정렬에는 두 개의 반복문이 필요합니다.

    # 바깥 반복: 전체 단계 수 (n-1번)
# 안쪽 반복: 각 단계에서 비교할 쌍의 수

    Step 2: 교환 로직 작성하기¶

    파이썬에서는 두 변수의 값을 간단히 교환할 수 있습니다.

    # 일반적인 방법 (임시 변수 사용)
temp = a
a = b
b = temp

# 파이썬의 간편한 방법 ✨
a, b = b, a

    Step 3: 전체 알고리즘 구현하기¶

    arr = [10, 6, 2, 4, 3]
n = len(arr)

print(f'정렬 전: {arr}')

for i in range(n - 1):              # n-1번의 단계
    for j in range(n - 1 - i):      # 각 단계에서 비교할 쌍
        if arr[j] > arr[j + 1]:     # 앞이 더 크면
            arr[j], arr[j + 1] = arr[j + 1], arr[j]  # 교환!
    print(f'{i+1}단계 후: {arr}')

print(f'최종 결과: {arr}')

1단계 후: [6, 2, 4, 3, 10]
2단계 후: [2, 4, 3, 6, 10]
3단계 후: [2, 3, 4, 6, 10]
4단계 후: [2, 3, 4, 6, 10]
최종 결과: [2, 3, 4, 6, 10]

    Step 5: 코드 분석하기¶

    flowchart TD A["시작: arr = [10,6,2,4,3]"] --> B["i = 0 (1단계)"] B --> C["j = 0,1,2,3 순서로<br/>인접 요소 비교·교환"] C --> D["i = 1 (2단계)"] D --> E["j = 0,1,2 순서로<br/>비교·교환"] E --> F["...반복..."] F --> G["정렬 완료!"]

    📝 전체 코드¶

    # ============================================
# 버블 정렬 (Bubble Sort) 완전한 구현
# ============================================

def bubble_sort(arr):
    """
    버블 정렬 함수
    - arr: 정렬할 리스트
    - 반환: 정렬된 리스트 (원본 리스트가 변경됨)
    """
    n = len(arr)

    for i in range(n - 1):
        # 각 단계에서 교환이 있었는지 확인
        swapped = False

        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True

        # 교환이 없었다면 이미 정렬 완료
        if not swapped:
            break

    return arr


# 테스트
if __name__ == "__main__":
    # 재활용 센터 폐기물 무게 데이터
    waste_weights = [10, 6, 2, 4, 3]

    print("♻️ 재활용 센터 폐기물 정렬")
    print(f"정렬 전: {waste_weights}")

    bubble_sort(waste_weights)

    print(f"정렬 후: {waste_weights}")
    print("가벼운 폐기물부터 처리할 준비 완료! 🎉")

    ⚠️ 자주 하는 실수¶

    실수 1: 반복 범위를 잘못 설정

    # ❌ 잘못된 코드
for i in range(n):           # n-1이 아닌 n 사용
    for j in range(n - i):   # n-1-i가 아닌 n-i 사용

# ✅ 올바른 코드
for i in range(n - 1):       # 총 n-1단계
    for j in range(n - 1 - i):  # 이미 고정된 요소 제외

    왜 틀릴까요? range(n-i)를 쓰면 arr[j+1]이 리스트 범위를 벗어나서 IndexError가 발생합니다.

    실수 2: 비교 방향 혼동

    # ❌ 잘못된 코드 (내림차순이 됨)
if arr[j] < arr[j + 1]:
    arr[j], arr[j + 1] = arr[j + 1], arr[j]

# ✅ 올바른 코드 (오름차순)
if arr[j] > arr[j + 1]:
    arr[j], arr[j + 1] = arr[j + 1], arr[j]

    실수 3: 교환 구문 오류

    # ❌ 잘못된 코드 (둘 다 같은 값이 됨)
arr[j] = arr[j + 1]
arr[j + 1] = arr[j]

# ✅ 올바른 코드 (동시에 교환)
arr[j], arr[j + 1] = arr[j + 1], arr[j]

    교환할 때는 반드시 임시 변수를 사용하거나 파이썬의 동시 할당 문법을 사용해야 합니다!

    • ③ [3, 5, 8, 1, 2]
    • ④ [5, 3, 1, 2, 8]
    정답 확인 **정답: ①** 1단계 과정: - 5와 3 비교 → 교환 → `[3, 5, 8, 1, 2]` - 5와 8 비교 → 그대로 - 8과 1 비교 → 교환 → `[3, 5, 1, 8, 2]` - 8과 2 비교 → 교환 → `[3, 5, 1, 2, 8]` 가장 큰 값 8이 맨 뒤로 이동했습니다.

    [확인 문제 2] 버블 정렬의 시간 복잡도가 O(n²)인 이유를 빈칸에 채워 완성하세요.

    데이터가 n개일 때, 1단계에서 (_)번, 2단계에서 ()번... 비교하므로 총 비교 횟수는 (__)번이다. 이를 빅오 표기법으로 나타내면 (_____)이다.

    정답 확인 > 데이터가 n개일 때, 1단계에서 **(n-1)**번, 2단계에서 **(n-2)**번... 비교하므로 총 비교 횟수는 **n(n-1)/2**번이다. 이를 빅오 표기법으로 나타내면 **O(n²)**이다.

    [도전 문제] 다음 데이터를 손으로 직접 버블 정렬해 보세요.

    [7, 4, 5, 2, 9, 1, 3, 8]

    각 단계가 끝난 후의 상태와 총 교환 횟수를 기록해 보세요.
