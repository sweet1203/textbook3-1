    🏥 5차시·6차시 통합 정리 — 탐색 알고리즘 총정리¶

    Part 4: 탐색 알고리즘 — 원하는 데이터를 효율적으로 찾는 방법

    🎯 이 장에서 배우는 것¶

    • 순차 탐색과 이진 탐색의 원리, 전제 조건, 성능을 비교하여 설명할 수 있다
    • 정렬과 탐색의 관계(정렬이 탐색 효율의 전제 조건)를 논리적으로 설명할 수 있다
    • 실생활에서 순차 탐색과 이진 탐색이 사용되는 사례를 각각 2가지 이상 제시할 수 있다

    📚 핵심 개념 총정리¶

    개념 1: 순차 탐색 vs 이진 탐색 — 두 탐색법의 핵심 차이¶

    비유로 이해하기 🔍

    순차 탐색은 도서관에서 책들이 뒤죽박죽 놓여 있을 때 첫 번째 책부터 하나씩 확인하는 것과 같아요. 반면 이진 탐색은 가나다순으로 정리된 사전에서 중간을 펼쳐 앞뒤를 판단하며 찾는 것과 같습니다.

    두 탐색법 비교

    flowchart LR subgraph 순차탐색["🔎 순차 탐색"] A1[첫 번째부터] --> A2[하나씩] --> A3[끝까지 확인] end subgraph 이진탐색["⚡ 이진 탐색"] B1[중간 확인] --> B2[범위 절반으로] --> B3[반복] end

    순차 탐색 핵심 정리 - 원리: 처음부터 끝까지 하나씩 비교 - 전제 조건: 없음 (정렬 불필요) - 성능: O(n) — 데이터가 많을수록 오래 걸림 - 장점: 구현이 쉽고, 어떤 데이터에도 사용 가능

    이진 탐색 핵심 정리 - 원리: 중간값과 비교하여 탐색 범위를 절반씩 축소 - 전제 조건: 반드시 정렬된 데이터 - 성능: O(log n) — 데이터가 많아도 빠름 - 장점: 대용량 데이터에서 압도적으로 빠름

    개념 2: 정렬과 탐색의 관계 — 왜 정렬이 중요한가?¶

    핵심 원리 📖

    "이진 탐색을 사용하려면 반드시 정렬이 선행되어야 한다"

    flowchart LR A["🔀 정렬되지 않은 데이터"] --> B["📊 정렬 수행"] B --> C["✅ 정렬된 데이터"] C --> D["⚡ 이진 탐색 가능"] A -.-> E["🔎 순차 탐색만 가능"]

    왜 정렬이 필요할까요?

    이진 탐색은 "중간값보다 크면 오른쪽, 작으면 왼쪽"이라는 판단을 합니다. 이 판단이 의미를 가지려면 데이터가 크기 순서대로 나열되어 있어야 해요.

    생각해보기 💭

    만약 [5, 2, 8, 1, 9]에서 '8'을 이진 탐색으로 찾는다면? - 중간값 8과 비교 → 찾았다! - 하지만 1을 찾는다면? 중간값 8보다 작으니 왼쪽을 보는데... [5, 2]에 1이 없어요!

    정렬되지 않은 데이터에서는 이진 탐색의 "범위 축소" 논리가 무너집니다.

    개념 3: 성능 비교 — 숫자로 확인하는 효율성¶

    1,000개 데이터에서 탐색할 때

    flowchart TB subgraph 성능비교["📊 최악의 경우 비교 횟수"] direction LR 순차["순차 탐색<br/>1,000번"] 이진["이진 탐색<br/>10번"] end

    데이터 크기별 비교 횟수 (최악의 경우)

    • 10개 데이터: 순차 10번 vs 이진 4번
    • 100개 데이터: 순차 100번 vs 이진 7번
    • 1,000개 데이터: 순차 1,000번 vs 이진 10번
    • 1,000,000개 데이터: 순차 1,000,000번 vs 이진 20번

    💡 데이터가 100만 개여도 이진 탐색은 단 20번 비교로 찾습니다!

    🔨 따라하기: 도서관 책 검색 시스템 만들기¶

    도서관에서 책을 검색하는 프로그램을 만들어 두 탐색법을 직접 비교해봅시다.

    Step 2: 순차 탐색 구현하기¶

    def sequential_search(data, target):
    """순차 탐색: 처음부터 끝까지 하나씩 확인"""
    count = 0  # 비교 횟수

    for i in range(len(data)):
        count += 1
        print(f"  {count}번째 비교: {data[i]}")
        if data[i] == target:
            return i, count  # 위치와 비교 횟수 반환

    return -1, count  # 못 찾은 경우

# 테스트
target = '어린왕자'
print(f"\n🔎 순차 탐색으로 '{target}' 찾기:")
result, comparisons = sequential_search(books, target)
print(f"→ {result}번 인덱스에서 발견! (비교 {comparisons}회)")

    실행 결과: 

    🔎 순차 탐색으로 '어린왕자' 찾기:
  1번째 비교: 괴물
  2번째 비교: 나미야 잡화점
  ...
  6번째 비교: 어린왕자
→ 5번 인덱스에서 발견! (비교 6회)

    Step 3: 이진 탐색 구현하기¶

    def binary_search(data, target):
    """이진 탐색: 중간값 비교로 범위를 절반씩 축소"""
    low = 0
    high = len(data) - 1
    count = 0

    while low <= high:
        count += 1
        mid = (low + high) // 2
        print(f"  {count}번째 비교: 중간값 {data[mid]} (인덱스 {mid})")

        if data[mid] == target:
            return mid, count
        elif data[mid] < target:
            low = mid + 1  # 오른쪽 절반 탐색
        else:
            high = mid - 1  # 왼쪽 절반 탐색

    return -1, count

# 테스트
print(f"\n⚡ 이진 탐색으로 '{target}' 찾기:")
result, comparisons = binary_search(books, target)
print(f"→ {result}번 인덱스에서 발견! (비교 {comparisons}회)")

    실행 결과: 

    ⚡ 이진 탐색으로 '어린왕자' 찾기:
  1번째 비교: 중간값 신데렐라 (인덱스 4)
  2번째 비교: 중간값 인어공주 (인덱스 6)
  3번째 비교: 중간값 어린왕자 (인덱스 5)
→ 5번 인덱스에서 발견! (비교 3회)

    Step 4: 두 탐색법 비교하기¶

    def compare_searches(data, target):
    """두 탐색법의 성능 비교"""
    print(f"\n{'='*40}")
    print(f"📊 '{target}' 탐색 성능 비교")
    print(f"{'='*40}")

    _, seq_count = sequential_search(data, target)
    _, bin_count = binary_search(data, target)

    print(f"\n📈 결과 요약:")
    print(f"  순차 탐색: {seq_count}회 비교")
    print(f"  이진 탐색: {bin_count}회 비교")
    print(f"  효율 차이: {seq_count - bin_count}회 절약!")

compare_searches(books, '흥부전')  # 마지막 책 검색

    📝 전체 코드¶

    # 🏥 탐색 알고리즘 총정리 - 도서관 책 검색 시스템

# 도서 데이터 (가나다순 정렬)
books = ['괴물', '나미야 잡화점', '데미안', '백설공주', 
         '신데렐라', '어린왕자', '인어공주', '콩쥐팥쥐', '해리포터', '흥부전']

def sequential_search(data, target):
    """순차 탐색"""
    for i in range(len(data)):
        if data[i] == target:
            return i, i + 1
    return -1, len(data)

def binary_search(data, target):
    """이진 탐색 (정렬된 데이터 필수)"""
    low, high, count = 0, len(data) - 1, 0
    while low <= high:
        count += 1
        mid = (low + high) // 2
        if data[mid] == target:
            return mid, count
        elif data[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1, count

# 탐색 실행 및 비교
target = input("찾을 책 제목: ")
seq_result, seq_count = sequential_search(books, target)
bin_result, bin_count = binary_search(books, target)

print(f"\n순차 탐색: {seq_count}회 비교")
print(f"이진 탐색: {bin_count}회 비교")

    ⚠️ 주의할 점¶

    1. 이진 탐색의 필수 조건을 잊지 마세요!

    이진 탐색은 정렬된 데이터에서만 올바르게 작동합니다. 정렬되지 않은 데이터에 이진 탐색을 적용하면 엉뚱한 결과가 나옵니다.

    2. 상황에 맞는 탐색법을 선택하세요

    • 데이터가 적거나 정렬되지 않았다면 → 순차 탐색
    • 데이터가 많고 정렬되어 있다면 → 이진 탐색

    ✅ 점검하기¶

    1. 이진 탐색을 사용하기 위한 필수 조건은 무엇인가요?

    정답 확인 데이터가 반드시 정렬되어 있어야 합니다. 정렬되지 않은 데이터에서는 이진 탐색의 "범위 축소" 논리가 작동하지 않습니다.

    2. 100만 개의 정렬된 데이터에서 특정 값을 찾을 때, 이진 탐색은 최대 몇 번 비교하나요?

    정답 확인 약 20번입니다. 이진 탐색은 매번 범위를 절반으로 줄이므로, 2^20 ≈ 1,000,000이 되어 최대 20번의 비교로 충분합니다.

    3. 실생활에서 순차 탐색과 이진 탐색이 사용되는 사례를 각각 2가지씩 제시해보세요.

    정답 확인 **순차 탐색 사례** - 정리되지 않은 서랍에서 물건 찾기 - 줄 서 있는 사람들 중 특정인 찾기 **이진 탐색 사례** - 영어사전에서 단어 찾기 - 전화번호부에서 이름으로 번호 검색하기
