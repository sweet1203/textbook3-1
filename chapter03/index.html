    학습 준비 — 웹 언플러그드 활동 체험하기¶

    🎯 이 장에서 배우는 것¶

    • 웹 기반 언플러그드 활동(클릭/드래그)의 사용 방법을 익힐 수 있다
    • VisuAlgo 사이트에서 정렬 알고리즘 시각화를 조작할 수 있다
    • CS Unplugged 사이트에서 이진 탐색 활동을 체험할 수 있다
    • 앞으로의 차시에서 활용할 학습 도구를 미리 탐색하고 준비할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 지금부터 알고리즘이라는 새로운 세계를 탐험하게 됩니다. 그런데 알고리즘은 눈에 보이지 않는 '절차'와 '논리'로 이루어져 있어서, 처음 접하면 막막하게 느껴질 수 있어요.

    생각해보기: 축구 경기 규칙을 글로만 읽는 것과, 실제 경기 영상을 보면서 배우는 것 중 어떤 게 더 이해가 잘 될까요?

    알고리즘도 마찬가지입니다! 시각화 도구를 활용하면 복잡한 정렬 과정이 어떻게 진행되는지 눈으로 직접 확인할 수 있고, 인터랙티브 활동을 통해 손으로 조작하며 원리를 체득할 수 있습니다.

    이번 시간은 본격적인 알고리즘 학습에 앞서 도구 사용법을 익히는 준비 운동 시간입니다. 마치 수영을 배우기 전에 물에 먼저 들어가 적응하는 것처럼, 앞으로 계속 사용할 웹 도구들과 친해지는 시간을 가져봅시다.

    flowchart LR A[추상적 개념] --> B[시각화 도구] B --> C[눈으로 확인] C --> D[손으로 조작] D --> E[깊은 이해] style A fill:#ffcccc style E fill:#ccffcc

    📚 핵심 개념¶

    개념 1: 언플러그드 활동이란?¶

    비유로 시작하기

    '언플러그드(Unplugged)'는 '플러그를 뽑은'이라는 뜻입니다. 원래는 컴퓨터 없이 종이, 카드, 몸동작 등을 활용해 컴퓨터 과학의 원리를 배우는 활동을 말해요. 마치 기타리스트가 전자 장비 없이 통기타만으로 연주하는 '언플러그드 공연'처럼요!

    정확한 정의

    • 전통적 언플러그드 활동: 컴퓨터 없이 물리적 도구(카드, 종이 등)로 컴퓨터 과학 원리를 학습하는 방법
    • 웹 언플러그드 활동: 전통적 언플러그드 활동을 웹 브라우저에서 클릭, 드래그 등으로 체험할 수 있도록 디지털화한 것

    예시로 확인

    flowchart TB subgraph 전통적["전통적 언플러그드"] A1[실제 카드 정렬하기] A2[종이에 이진수 표현하기] A3[친구들과 네트워크 역할극] end subgraph 웹["웹 언플러그드"] B1[화면의 카드 드래그하기] B2[버튼 클릭으로 이진수 변환] B3[시뮬레이션으로 네트워크 체험] end 전통적 -.->|디지털화| 웹

    알아보기: 웹 언플러그드의 장점은 언제 어디서나 혼자서도 반복 학습이 가능하다는 점입니다. 실수해도 리셋 버튼 하나로 처음부터 다시 시작할 수 있어요!

    개념 2: 알고리즘 시각화 도구¶

    비유로 시작하기

    요리 레시피를 읽는 것과 요리 과정을 담은 영상을 보는 것, 어떤 게 더 이해하기 쉬울까요? 알고리즘 시각화 도구는 '알고리즘 레시피'를 '영상'처럼 보여주는 도구입니다.

    정확한 정의

    알고리즘 시각화(Algorithm Visualization) 도구는 알고리즘의 실행 과정을 그래픽, 애니메이션, 색상 변화 등으로 표현하여 학습자가 각 단계를 직관적으로 이해할 수 있게 돕는 소프트웨어입니다.

    주요 시각화 도구 소개

    • VisuAlgo: 싱가포르 국립대학교에서 개발한 알고리즘 시각화 플랫폼. 정렬, 탐색, 그래프 등 다양한 알고리즘을 애니메이션으로 학습
    • Algorithm Visualizer: 다양한 알고리즘을 단계별로 시각화하며 코드와 함께 보여줌
    • CS Unplugged: 뉴질랜드에서 시작된 언플러그드 교육 프로젝트의 공식 웹사이트

    예시로 확인

    버블 정렬 과정을 시각화 도구로 보면:

    flowchart LR subgraph 단계1["1단계"] direction LR A1["5"] --> A2["3"] A2 --> A3["8"] A3 --> A4["1"] end subgraph 단계2["비교 중"] direction LR B1["3"]:::highlight --> B2["5"]:::highlight B2 --> B3["8"] B3 --> B4["1"] end subgraph 단계3["교환 완료"] direction LR C1["3"] --> C2["5"] C2 --> C3["1"]:::highlight C3 --> C4["8"]:::highlight end classDef highlight fill:#ffeb3b

    숫자들이 비교되고, 위치가 바뀌는 과정이 색상 변화와 애니메이션으로 실시간 표시됩니다!

    개념 3: VisuAlgo 소개¶

    비유로 시작하기

    VisuAlgo는 '알고리즘 놀이공원'과 같습니다. 정렬, 탐색, 그래프 등 다양한 '놀이기구(알고리즘)'가 있고, 여러분은 원하는 놀이기구를 골라 직접 체험할 수 있어요.

    정확한 정의

    VisuAlgo는 싱가포르 국립대학교(NUS)의 Steven Halim 교수팀이 개발한 무료 알고리즘 학습 플랫폼입니다. 정렬, 연결 리스트, 이진 트리, 그래프 탐색 등 30개 이상의 자료구조와 알고리즘을 인터랙티브 애니메이션으로 제공합니다.

    VisuAlgo의 주요 기능

    • 속도 조절: 애니메이션 속도를 느리게/빠르게 조절
    • 단계별 실행: 한 단계씩 버튼을 눌러 진행
    • 입력 데이터 변경: 원하는 숫자 배열로 직접 실험
    • 한국어 지원: 설정에서 한국어로 변경 가능

    접속 주소: https://visualgo.net

    flowchart TB A[VisuAlgo 접속] --> B{카테고리 선택} B --> C[Sorting 정렬] B --> D[Linked List 연결 리스트] B --> E[Binary Search Tree 이진 탐색 트리] B --> F[Graph 그래프] C --> G[버블/삽입/퀵 정렬 등] G --> H[▶ 재생 버튼으로 시작]

    개념 4: CS Unplugged 소개¶

    비유로 시작하기

    CS Unplugged는 '컴퓨터 과학 체험관'입니다. 박물관에서 전시물을 직접 만지고 조작해보듯이, 컴퓨터 과학의 핵심 개념들을 게임처럼 체험할 수 있어요.

    정확한 정의

    CS Unplugged는 뉴질랜드 캔터베리 대학교에서 시작된 컴퓨터 과학 교육 프로젝트입니다. 원래 컴퓨터 없이 진행하는 활동들을 모아놓은 것인데, 현재는 웹에서 체험할 수 있는 인터랙티브 버전도 제공합니다.

    주요 활동 영역

    • 이진수: 카드 뒤집기로 이진법 이해
    • 이미지 표현: 픽셀과 비트맵 원리
    • 오류 검출: 패리티 비트로 오류 찾기
    • 탐색 알고리즘: 숫자 찾기 게임으로 이진 탐색 체험
    • 정렬 네트워크: 비교 연산 시각화

    접속 주소: https://www.csunplugged.org

    🔨 따라하기¶

    준비물: 인터넷이 연결된 컴퓨터 또는 태블릿, 웹 브라우저(크롬 권장)

    Step 1: VisuAlgo 접속하기¶

    1-1. 웹 브라우저를 열고 주소창에 입력하세요

    https://visualgo.net

    1-2. 메인 화면 확인하기

    접속하면 다양한 알고리즘 카테고리가 카드 형태로 나열된 화면이 보입니다.

    flowchart TB subgraph 메인화면["VisuAlgo 메인 화면"] A[Sorting<br>정렬] B[Linked List<br>연결 리스트] C[Hash Table<br>해시 테이블] D[BST<br>이진 탐색 트리] E[... 더 많은 항목들] end

    1-3. 한국어로 변경하기 (선택사항)

    화면 우측 상단의 언어 설정에서 'Korean(한국어)'을 선택하면 설명이 한국어로 표시됩니다.

    정리하기: VisuAlgo는 무료이며 회원가입 없이 바로 사용할 수 있습니다!

    Step 2: VisuAlgo에서 정렬 시각화 체험하기¶

    2-1. Sorting(정렬) 메뉴 클릭

    메인 화면에서 "Sorting" 카드를 클릭하세요.

    2-2. 화면 구성 이해하기

    정렬 페이지는 크게 세 영역으로 구성됩니다:

    flowchart TB subgraph 상단["① 컨트롤 영역"] A1[Create 배열 생성] A2[Sort 정렬 시작] A3[◀ ▶ 단계 이동] end subgraph 중앙["② 시각화 영역"] B1[막대 그래프로<br>숫자 배열 표시] end subgraph 하단["③ 설명 영역"] C1[현재 진행 중인<br>단계 설명] end 상단 --> 중앙 --> 하단

    2-3. 새로운 배열 만들기

    1. 상단의 "Create" 버튼 클릭
    2. "Random" 선택하여 무작위 숫자 배열 생성
    3. 또는 "User Defined"를 선택해 직접 숫자 입력 (예: 5,3,8,1,9,2)

    2-4. 버블 정렬 실행해보기

    1. "Sort" 버튼 클릭
    2. 드롭다운 메뉴에서 "Bubble Sort" 선택
    3. "Go" 또는 재생 버튼(▶) 클릭

    2-5. 애니메이션 관찰하기

    • 두 개의 막대가 노란색으로 변하면 → 현재 비교 중
    • 막대 위치가 바뀌면 → 교환(swap) 발생
    • 막대가 초록색으로 변하면 → 정렬 완료된 위치

    생각해보기: 버블 정렬에서 가장 큰 숫자는 어디로 이동하나요? 애니메이션을 보며 확인해보세요!

    Step 3: VisuAlgo 속도 조절하기¶

    애니메이션이 너무 빠르거나 느리다면 속도를 조절할 수 있습니다.

    3-1. 속도 조절 방법

    • 화면 하단 또는 설정 영역에서 슬라이더 찾기
    • 왼쪽으로 이동 = 느리게 (천천히 관찰할 때)
    • 오른쪽으로 이동 = 빠르게 (전체 흐름 파악할 때)

    3-2. 단계별 실행 방법

    한 단계씩 직접 진행하고 싶다면:

    1. 재생 버튼 대신 "Step" 버튼 또는 ▶| 버튼 사용
    2. 클릭할 때마다 한 단계씩 진행
    3. 각 단계에서 무슨 일이 일어나는지 하단 설명 확인
    sequenceDiagram participant 사용자 participant VisuAlgo 사용자->>VisuAlgo: Step 버튼 클릭 VisuAlgo->>사용자: 1단계 실행 + 설명 표시 사용자->>VisuAlgo: Step 버튼 클릭 VisuAlgo->>사용자: 2단계 실행 + 설명 표시 Note over 사용자,VisuAlgo: 원하는 만큼 반복

    Step 4: CS Unplugged 접속하기¶

    4-1. 웹 브라우저에서 접속

    https://www.csunplugged.org

    4-2. 메인 화면 탐색

    CS Unplugged 웹사이트는 다양한 주제별 활동을 제공합니다.

    flowchart LR A[CS Unplugged] --> B[Topics 주제별 활동] A --> C[Resources 교육 자료] A --> D[At Home 가정 학습] B --> B1[Binary Numbers 이진수] B --> B2[Sorting Networks 정렬] B --> B3[Searching Algorithms 탐색]

    4-3. 인터랙티브 활동 찾기

    1. 메뉴에서 "Topics" 또는 "Interactives" 클릭
    2. "Binary Numbers" (이진수) 활동 선택
    3. 카드를 클릭하여 이진수를 만들어보는 활동 체험

    Step 5: CS Unplugged 이진 탐색 체험하기¶

    5-1. Searching Algorithms 활동 찾기

    CS Unplugged에서 제공하는 탐색 관련 인터랙티브 활동을 찾아봅시다.

    알아보기: 정확한 메뉴 구조는 사이트 업데이트에 따라 달라질 수 있습니다. "Searching" 또는 "Binary Search"로 검색해보세요.

    5-2. 숫자 찾기 게임 원리

    이진 탐색의 원리를 체험하는 활동입니다:

    flowchart TB A[1~100 중 숨겨진 숫자 찾기] --> B{중간값 50과 비교} B -->|"더 크다"| C[51~100 범위로 축소] B -->|"더 작다"| D[1~49 범위로 축소] C --> E{중간값 75와 비교} D --> F{중간값 25와 비교} E --> G[...반복...] F --> G G --> H[정답 발견!]

    5-3. 체험 방법

    1. 화면에 1부터 특정 숫자까지의 카드가 뒤집어져 있음
    2. 중간 카드를 클릭하여 확인
    3. 힌트(더 큼/더 작음)를 보고 범위를 절반으로 줄임
    4. 최소한의 시도로 목표 숫자 찾기!

    Step 6: 도구 비교 및 정리¶

    두 도구를 체험해보았으니, 각각의 특징을 정리해봅시다.

    VisuAlgo의 특징

    • 알고리즘 실행 과정을 애니메이션으로 시각화
    • 코드와 연계하여 학습 가능
    • 정렬, 탐색, 그래프 등 다양한 알고리즘 제공
    • 속도 조절, 단계별 실행 등 세밀한 컨트롤 가능

    CS Unplugged의 특징

    • 컴퓨터 과학의 핵심 원리에 집중
    • 게임처럼 즐기며 학습
    • 개념 이해에 초점 (코드 없이도 가능)
    • 오프라인 활동과 연계 가능

    ⚠️ 자주 하는 실수¶

    실수 1: 사이트 주소를 잘못 입력하는 경우¶

    문제 상황: visualgo.com이나 csunplugged.com으로 접속

    올바른 해결: - VisuAlgo → visualgo.net (.net입니다!) - CS Unplugged → csunplugged.org (.org입니다!)

    정리하기: 사이트 주소의 뒷부분(.com, .net, .org)까지 정확히 입력해야 합니다. 검색엔진에서 사이트 이름으로 검색해도 좋습니다.

    실수 2: 애니메이션이 너무 빨라서 놓치는 경우¶

    문제 상황: 재생 버튼을 눌렀는데 순식간에 끝나버림

    올바른 해결: 1. 속도 조절 슬라이더를 왼쪽 끝으로 이동 (가장 느리게) 2. 또는 Step 버튼을 사용하여 한 단계씩 진행 3. 처음부터 다시 보고 싶다면 Reset 또는 Create로 초기화

    실수 3: 영어 때문에 이해가 어려운 경우¶

    문제 상황: 메뉴나 설명이 영어로 되어있어 어려움

    올바른 해결: - VisuAlgo: 우측 상단에서 언어를 Korean으로 변경 - CS Unplugged: 브라우저의 번역 기능 활용 (크롬: 우클릭 → 한국어로 번역) - 모르는 단어가 나오면 메모해두고 선생님께 질문!

    자주 나오는 영어 단어

    • Sort: 정렬하다
    • Create: 생성하다
    • Random: 무작위의
    • Step: 단계
    • Speed: 속도
    • Pause: 일시정지

    실수 4: 인터넷 연결 문제¶

    문제 상황: 페이지가 로딩되지 않거나 애니메이션이 끊김

    올바른 해결: 1. 인터넷 연결 상태 확인 2. 페이지 새로고침 (F5 또는 Ctrl+R) 3. 다른 브라우저로 시도 (크롬 권장) 4. 학교 네트워크에서 차단되었을 수 있음 → 선생님께 문의
