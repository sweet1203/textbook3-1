    🍱 취약계층 지원 대상 찾기 — 순차 탐색의 원리¶

    Part 4: 탐색 알고리즘 — 원하는 데이터를 효율적으로 찾는 방법

    🎯 이 장에서 배우는 것¶

    • 순차 탐색의 정의와 작동 원리(처음부터 끝까지 순서대로 비교)를 설명할 수 있다
    • 주어진 데이터에서 순차 탐색을 손으로 직접 수행하고 비교 횟수를 기록할 수 있다
    • 순차 탐색의 장점(정렬 불필요)과 단점(데이터가 많을수록 느림)을 설명할 수 있다
    • 파이썬으로 순차 탐색 알고리즘을 구현할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    여러분이 동사무소 복지 담당자라고 상상해보세요. 500명의 주민 명단에서 긴급 지원이 필요한 "김복지" 님을 찾아야 합니다. 명단은 등록 순서대로 되어 있어서 가나다순이 아닙니다. 어떻게 찾으시겠어요?

    아마 대부분 이렇게 할 겁니다: 1. 첫 번째 이름을 확인한다 → "김복지"가 아니네 2. 두 번째 이름을 확인한다 → 이것도 아니네 3. 계속 확인하다가... 찾았다!

    이것이 바로 순차 탐색입니다. 가장 직관적이고 단순한 방법이죠.

    우리 일상에서도 순차 탐색을 자주 사용합니다: - 📚 정리되지 않은 책더미에서 특정 책 찾기 - 🎵 재생목록에서 듣고 싶은 노래 찾기 - 📱 채팅방 목록에서 친구 찾기

    탐색 알고리즘은 데이터에서 원하는 정보를 찾는 방법입니다. 효율적인 탐색은 검색 엔진, 데이터베이스, 인공지능 등 모든 정보 시스템의 핵심입니다.

    📚 핵심 개념¶

    개념 1: 탐색이란?¶

    🎪 비유로 시작

    놀이공원에서 친구를 찾는다고 생각해보세요. 친구가 어디 있는지 모르면 어떻게 할까요? 입구부터 시작해서 한 장소씩 확인하며 돌아다닐 겁니다. 이것이 "탐색"입니다.

    📖 정확한 정의

    탐색(Search): 여러 데이터 중에서 원하는 데이터를 찾는 과정

    ✅ 예시로 확인

    데이터: [사과, 바나나, 포도, 딸기, 수박]
찾는 값: 포도
결과: 3번째 위치에서 발견!

    개념 2: 순차 탐색의 정의¶

    🎪 비유로 시작

    도서관에서 책을 찾는데, 책들이 제목순으로 정리되어 있지 않다면? 첫 번째 책꽂이부터 하나씩 확인하는 수밖에 없습니다. 지루하지만 확실한 방법이죠.

    📖 정확한 정의

    순차 탐색(Sequential Search): 리스트의 첫 번째 요소부터 마지막 요소까지 순서대로 비교하면서 원하는 값을 찾는 알고리즘

    핵심 특징 - 선형 탐색(Linear Search)이라고도 부릅니다 - 데이터가 정렬되어 있지 않아도 사용 가능 - 구현이 매우 간단함

    ✅ 예시로 확인

    10명의 이름 목록에서 "윤예은"을 찾아봅시다:

    목록: [강수빈, 김서연, 이효주, 박민서, 윤예은, 최지민, 김하은, 한윤서, 이서준, 김지우]
    flowchart LR A["1️⃣ 강수빈"] --> B["2️⃣ 김서연"] B --> C["3️⃣ 이효주"] C --> D["4️⃣ 박민서"] D --> E["5️⃣ 윤예은 ✓"] style E fill:#90EE90

    5번 비교 만에 찾았습니다!

    개념 3: 순차 탐색의 작동 원리¶

    🎪 비유로 시작

    줄 서 있는 사람들에게 "김철수 씨 계세요?"라고 물어보는 것과 같습니다. 맨 앞 사람부터 차례로 물어보고, "네, 접니다!"라고 답하면 탐색 종료!

    📖 정확한 정의 - 알고리즘 단계

    flowchart TD A[시작] --> B[첫 번째 요소 선택] B --> C{찾는 값과 같은가?} C -->|예| D[위치 반환, 탐색 종료] C -->|아니오| E{마지막 요소인가?} E -->|아니오| F[다음 요소로 이동] F --> C E -->|예| G[찾는 값 없음 반환] D --> H[종료] G --> H

    ✅ 예시로 확인 - 단계별 추적

    복지 수급 대상자 목록에서 "이영희"를 찾아봅시다:

    목록: [김철수, 박영수, 최민지, 이영희, 정대호]
찾는 값: 이영희

    1단계: 김철수 확인 → "이영희"와 다름 → 다음으로

    2단계: 박영수 확인 → "이영희"와 다름 → 다음으로

    3단계: 최민지 확인 → "이영희"와 다름 → 다음으로

    4단계: 이영희 확인 → "이영희"와 같음 → 찾았다!

    결과: 비교 횟수 = 4회, 위치 = 4번째(인덱스 3)

    개념 4: 최선의 경우와 최악의 경우¶

    🎪 비유로 시작

    운이 좋으면 첫 번째 책에서 바로 찾고, 운이 나쁘면 마지막 책까지 다 뒤져야 합니다. 아니면 아예 없을 수도 있죠!

    📖 정확한 정의

    최선의 경우(Best Case): 찾는 값이 맨 앞에 있을 때 → 비교 1회

    최악의 경우(Worst Case): 찾는 값이 맨 뒤에 있거나 없을 때 → 비교 n회

    평균적인 경우(Average Case): 무작위 위치에 있을 때 → 약 n/2회

    ✅ 예시로 확인

    5명의 데이터에서 탐색하는 경우:

    데이터: [A, B, C, D, E]
    • A를 찾을 때: 비교 1회 (최선)
    • C를 찾을 때: 비교 3회 (평균)
    • E를 찾을 때: 비교 5회 (최악)
    • F를 찾을 때: 비교 5회 후 "없음" (최악)

    시간 복잡도: O(n) — 데이터가 n개면 최대 n번 비교

    🔨 따라하기¶

    복지 담당자가 긴급 지원 대상자를 찾는 프로그램을 만들어봅시다.

    Step 1: 기본 순차 탐색 함수 만들기¶

    먼저 가장 기본적인 순차 탐색 함수를 작성합니다.

    def sequential_search(data_list, target):
    """
    순차 탐색 함수
    data_list: 탐색할 데이터 목록
    target: 찾고자 하는 값
    반환: 찾으면 위치(인덱스), 못 찾으면 -1
    """
    for i in range(len(data_list)):
        if data_list[i] == target:
            return i  # 찾으면 위치 반환
    return -1  # 끝까지 못 찾으면 -1 반환

    Step 2: 탐색 과정 시각화하기¶

    비교 횟수를 세면서 과정을 출력해봅시다.

    def sequential_search_verbose(data_list, target):
    """
    과정을 출력하는 순차 탐색
    """
    print(f"🔍 '{target}'을(를) 찾습니다...")
    print(f"📋 데이터: {data_list}")
    print("-" * 40)

    count = 0  # 비교 횟수

    for i in range(len(data_list)):
        count += 1
        current = data_list[i]

        if current == target:
            print(f"✅ {count}번째 비교: '{current}' → 찾았습니다!")
            print(f"\n결과: {i}번 인덱스에서 발견 (비교 {count}회)")
            return i
        else:
            print(f"❌ {count}번째 비교: '{current}' → 다릅니다")

    print(f"\n결과: 찾지 못했습니다 (비교 {count}회)")
    return -1

    Step 3: 실제 데이터로 테스트하기¶

    복지 지원 대상자 명단을 만들고 탐색해봅시다.

    # 취약계층 지원 대상자 명단 (등록 순서)
recipients = ["김영수", "이순자", "박민호", "최영희", "정대철", 
              "강수빈", "윤미경", "조성민", "한지원", "임서연"]

# 테스트 1: 중간에 있는 사람 찾기
print("=" * 50)
print("테스트 1: 정대철 찾기")
print("=" * 50)
result = sequential_search_verbose(recipients, "정대철")

    Step 4: 다양한 경우 테스트하기¶

    # 테스트 2: 맨 앞에 있는 사람 (최선의 경우)
print("\n" + "=" * 50)
print("테스트 2: 김영수 찾기 (최선의 경우)")
print("=" * 50)
sequential_search_verbose(recipients, "김영수")

# 테스트 3: 맨 뒤에 있는 사람 (최악의 경우)
print("\n" + "=" * 50)
print("테스트 3: 임서연 찾기 (최악의 경우)")
print("=" * 50)
sequential_search_verbose(recipients, "임서연")

# 테스트 4: 없는 사람 (최악의 경우)
print("\n" + "=" * 50)
print("테스트 4: 홍길동 찾기 (존재하지 않음)")
print("=" * 50)
sequential_search_verbose(recipients, "홍길동")

    Step 5: 비교 횟수 통계 내기¶

    def analyze_search_performance(data_list):
    """
    모든 요소를 찾을 때 비교 횟수 분석
    """
    print(f"\n📊 순차 탐색 성능 분석")
    print(f"데이터 개수: {len(data_list)}개")
    print("-" * 40)

    total_comparisons = 0

    for i, item in enumerate(data_list):
        comparisons = i + 1  # 해당 위치까지 비교 횟수
        total_comparisons += comparisons
        print(f"'{item}' 찾기: {comparisons}회 비교")

    average = total_comparisons / len(data_list)
    print("-" * 40)
    print(f"최선의 경우: 1회")
    print(f"최악의 경우: {len(data_list)}회")
    print(f"평균 비교 횟수: {average:.1f}회")

# 분석 실행
analyze_search_performance(recipients)

    📝 전체 코드¶

    # ============================================
# 취약계층 지원 대상 찾기 - 순차 탐색 프로그램
# ============================================

def sequential_search(data_list, target):
    """
    순차 탐색 함수 (기본 버전)
    """
    for i in range(len(data_list)):
        if data_list[i] == target:
            return i
    return -1


def sequential_search_verbose(data_list, target):
    """
    순차 탐색 함수 (과정 출력 버전)
    """
    print(f"🔍 '{target}'을(를) 찾습니다...")
    print(f"📋 데이터: {data_list}")
    print("-" * 40)

    count = 0

    for i in range(len(data_list)):
        count += 1
        current = data_list[i]

        if current == target:
            print(f"✅ {count}번째 비교: '{current}' → 찾았습니다!")
            print(f"\n결과: {i}번 인덱스에서 발견 (비교 {count}회)")
            return i
        else:
            print(f"❌ {count}번째 비교: '{current}' → 다릅니다")

    print(f"\n결과: 찾지 못했습니다 (비교 {count}회)")
    return -1


def analyze_search_performance(data_list):
    """
    순차 탐색 성능 분석
    """
    print(f"\n📊 순차 탐색 성능 분석")
    print(f"데이터 개수: {len(data_list)}개")
    print("-" * 40)

    total = 0
    for i, item in enumerate(data_list):
        comp = i + 1
        total += comp
        print(f"'{item}' 찾기: {comp}회 비교")

    avg = total / len(data_list)
    print("-" * 40)
    print(f"최선: 1회 | 최악: {len(data_list)}회 | 평균: {avg:.1f}회")

    💡 기억하세요: 인덱스 i에 있는 요소를 찾으려면 비교 횟수는 i + 1번입니다!

    실수 2: 찾지 못한 경우 처리 누락¶

    # ❌ 문제가 있는 코드
def bad_search(data, target):
    for i in range(len(data)):
        if data[i] == target:
            return i
    # 못 찾으면 아무것도 반환 안 함 → None 반환됨

result = bad_search(["A", "B"], "C")
print(result + 1)  # TypeError 발생!

# ✅ 올바른 코드
def good_search(data, target):
    for i in range(len(data)):
        if data[i] == target:
            return i
    return -1  # 명시적으로 -1 반환

result = good_search(["A", "B"], "C")
if result != -1:
    print(f"위치: {result}")
else:
    print("찾지 못했습니다")

def search_ignore_case(data, target):
    target_lower = target.lower()
    for i in range(len(data)):
        if data[i].lower() == target_lower:
            return i
    return -1

    확인 문제 1 (개념 이해)¶

    다음 중 순차 탐색에 대한 설명으로 올바른 것을 모두 고르세요.

    1. 데이터가 반드시 정렬되어 있어야 한다
    2. 첫 번째 요소부터 마지막까지 차례로 비교한다
    3. 최선의 경우 비교 1회로 찾을 수 있다
    4. 데이터가 100개면 최악의 경우 100회 비교한다
    정답 확인 **정답: 2, 3, 4** 1번은 틀렸습니다. 순차 탐색의 장점은 **정렬되지 않은 데이터에서도 사용 가능**하다는 것입니다.

    확인 문제 2 (비교 횟수 계산)¶

    다음 데이터에서 각 값을 찾을 때 비교 횟수를 적으세요.

    데이터: [10, 25, 8, 17, 33, 42, 15]
    • 10을 찾을 때: ___회
    • 33을 찾을 때: ___회
    • 50을 찾을 때: ___회
    정답 확인 - **10을 찾을 때: 1회** (맨 앞에 있음) - **33을 찾을 때: 5회** (인덱스 4에 있음, 4+1=5) - **50을 찾을 때: 7회** (없으므로 끝까지 탐색)

    정리하기 📌

    이번 장에서 우리는 순차 탐색을 배웠습니다. - 작동 원리: 처음부터 끝까지 하나씩 비교 - 장점: 정렬 없이 사용 가능, 구현이 간단 - 단점: 데이터가 많으면 느림 (최대 n번 비교) - 시간 복잡도: O(n)

    순차 탐색은 직관적이지만, 데이터가 1,000개, 10,000개, 100만 개가 되면 어떨까요? 매우 느려집니다!

    핵심 개념 요약

    • 탐색: 데이터에서 원하는 값을 찾는 과정
    • 순차 탐색: 처음부터 끝까지 순서대로 비교하는 방법
    • 최선의 경우: 첫 번째에서 발견 (비교 1회)

    • 시간 복잡도: O(n) — 데이터 수에 비례
