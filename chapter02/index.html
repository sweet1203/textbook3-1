    컴퓨팅으로 해결할 수 있는 문제란? — 문제의 상태 이해하기¶

    🎯 이 장에서 배우는 것¶

    • 컴퓨팅 시스템으로 해결할 수 있는 문제의 3가지 특징(초기 상태, 목표 상태, 수행 과정)을 설명할 수 있다
    • 주어진 문제 상황에서 초기 상태와 목표 상태를 구분할 수 있다
    • 문제 해결 과정을 단계별로 서술할 수 있다

    💭 생각해보기: 미로를 탈출하라!¶

    여러분 앞에 미로가 있습니다. 입구에 서 있는 당신은 출구를 찾아 빠져나가야 합니다.

    flowchart LR A["🚶 입구<br/>(시작 지점)"] --> B["???<br/>(어떤 경로?)"] --> C["🚪 출구<br/>(도착 지점)"]

    잠깐 생각해 봅시다.

    질문 1: 미로 탈출에서 '시작'은 어디인가요?

    질문 2: '끝'은 어디인가요?

    질문 3: 시작에서 끝까지 어떻게 이동하나요?

    이 세 가지 질문에 답할 수 있다면, 여러분은 이미 컴퓨팅으로 해결할 수 있는 문제의 핵심을 파악한 것입니다!

    📚 핵심 개념¶

    개념 1: 초기 상태 (Initial State)¶

    비유로 시작하기 🎮

    초기 상태는 마치 게임을 처음 시작했을 때의 화면과 같아요. 아직 아무것도 진행되지 않은, 문제가 주어진 그 순간의 모습입니다.

    정확한 정의

    초기 상태란 문제 해결을 시작하기 전, 가장 처음의 상태를 말합니다. "지금 어떤 상황인가?"에 대한 답입니다.

    예시로 확인

    • 미로 찾기: 입구에 서 있는 상태
    • 요리하기: 재료가 손질되지 않은 상태
    • 시험 공부: 아직 책을 펴지 않은 상태

    개념 2: 목표 상태 (Goal State)¶

    비유로 시작하기 🏆

    목표 상태는 게임에서 "축하합니다! 클리어!"가 뜨는 순간과 같아요. 우리가 원하는 결과에 도달한 상태입니다.

    정확한 정의

    목표 상태란 문제가 해결된 상태를 말합니다. "어떤 상태가 되어야 하는가?"에 대한 답입니다.

    예시로 확인

    • 미로 찾기: 출구에 도착한 상태
    • 요리하기: 완성된 음식이 접시에 담긴 상태
    • 시험 공부: 시험 범위를 모두 이해한 상태

    개념 3: 수행 과정 (Process)¶

    비유로 시작하기 🗺️

    수행 과정은 목적지까지 가는 내비게이션 경로와 같아요. 시작점에서 도착점까지 어떤 행동을 해야 하는지 알려주는 단계별 안내입니다.

    정확한 정의

    수행 과정이란 초기 상태에서 목표 상태로 변화시키기 위해 필요한 일련의 행동 또는 단계입니다.

    예시로 확인

    • 미로 찾기: "직진 → 왼쪽 → 직진 → 오른쪽 → ..."
    • 요리하기: "재료 손질 → 볶기 → 간 맞추기 → 담기"
    • 시험 공부: "개념 읽기 → 문제 풀기 → 오답 정리"

    🔍 알아보기: 컴퓨팅으로 해결 가능한 문제의 조건¶

    컴퓨터가 문제를 해결하려면 세 가지가 명확해야 합니다.

    flowchart TB subgraph 문제의 3요소 A["🟢 초기 상태<br/>지금 어떤 상황인가?"] B["🔴 목표 상태<br/>어떤 상태가 되어야 하는가?"] C["🔵 수행 과정<br/>어떻게 변화시킬 것인가?"] end A --> C --> B

    세 가지 중 하나라도 불명확하면 컴퓨터는 문제를 해결할 수 없습니다!

    🔨 따라하기: 문제의 상태 분석하기¶

    Step 1: 일상 속 문제 분석해보기¶

    문제 상황: "어두운 방을 밝게 만들어라"

    이 문제를 세 가지 요소로 분석해 봅시다.

    분석 결과: - 초기 상태: 방이 어둡다 (전등이 꺼져 있다) - 목표 상태: 방이 밝다 (전등이 켜져 있다) - 수행 과정: 전등 스위치를 누른다

    Step 2: 숫자 정렬 문제 분석하기¶

    문제 상황: "숫자 카드 [3, 1, 4, 2]를 작은 순서대로 정렬하라"

    분석 결과: - 초기 상태: [3, 1, 4, 2] — 정렬되지 않은 상태 - 목표 상태: [1, 2, 3, 4] — 오름차순 정렬된 상태 - 수행 과정: 숫자를 비교하고 위치를 교환하는 과정 반복

    flowchart LR A["[3, 1, 4, 2]<br/>초기 상태"] B["비교 & 교환<br/>수행 과정"] C["[1, 2, 3, 4]<br/>목표 상태"] A --> B --> C

    Step 3: 파이썬으로 상태 표현하기¶

    문제의 상태를 코드로 표현해 봅시다.

    코드: 

    # 숫자 정렬 문제의 상태 정의
initial_state = [3, 1, 4, 2]  # 초기 상태
goal_state = [1, 2, 3, 4]     # 목표 상태

print("초기 상태:", initial_state)
print("목표 상태:", goal_state)

# 현재 상태가 목표 상태인지 확인
if initial_state == goal_state:
    print("문제 해결 완료!")
else:
    print("아직 해결되지 않았습니다.")

    실행 결과: 

    초기 상태: [3, 1, 4, 2]
목표 상태: [1, 2, 3, 4]
아직 해결되지 않았습니다.

    Step 4: 수행 과정 구현하기¶

    이제 초기 상태를 목표 상태로 바꾸는 수행 과정을 추가합니다.

    코드: 

    # 초기 상태
current_state = [3, 1, 4, 2]
goal_state = [1, 2, 3, 4]

print("초기 상태:", current_state)

# 수행 과정: 정렬하기
current_state.sort()  # 파이썬 내장 정렬 기능 사용

print("수행 후 상태:", current_state)

# 목표 도달 확인
if current_state == goal_state:
    print("🎉 문제 해결 완료!")

    실행 결과: 

    초기 상태: [3, 1, 4, 2]
수행 후 상태: [1, 2, 3, 4]
🎉 문제 해결 완료!

    📝 전체 코드¶

    # === 컴퓨팅 문제의 3요소 실습 ===

# 1. 상태 정의
initial_state = [3, 1, 4, 2]  # 초기 상태
goal_state = [1, 2, 3, 4]     # 목표 상태
current_state = initial_state.copy()  # 현재 상태 (초기값 복사)

# 2. 상태 출력
print("=== 문제 분석 ===")
print("초기 상태:", initial_state)
print("목표 상태:", goal_state)

# 3. 수행 과정 실행
print("\n=== 수행 과정 ===")
current_state.sort()
print("정렬 수행 완료")

# 4. 결과 확인
print("\n=== 결과 확인 ===")
print("현재 상태:", current_state)

if current_state == goal_state:
    print("✅ 목표 상태에 도달했습니다!")
else:
    print("❌ 아직 목표에 도달하지 못했습니다.")

    ⚠️ 주의할 점¶

    1. 목표 상태가 불명확하면 해결할 수 없습니다

    "좋은 성적을 받아라"는 컴퓨터가 해결할 수 없는 문제입니다. "좋은"이 무엇인지 명확하지 않기 때문이죠. "수학 점수 90점 이상"처럼 구체적으로 정의해야 합니다.

    2. 초기 상태를 정확히 파악해야 합니다

    현재 어떤 상황인지 모르면 어디서부터 시작해야 할지 알 수 없습니다. 문제 해결의 첫걸음은 "지금 상태"를 정확히 아는 것입니다.

    다음 조건을 만족하는 시간표를 만드세요. - 과목: 국어, 수학, 영어, 과학 - 1~4교시에 배치 - 각 과목은 한 번씩만

    여러분이 할 일: 아래 질문에 답해보세요.

    Q1: 초기 상태는 무엇인가요?

    Q2: 목표 상태는 무엇인가요?

    Q3: 수행 과정은 무엇인가요?

    💡 힌트 보기 - 초기 상태: 빈 시간표 + 배치해야 할 과목 목록 - 목표 상태: 4개 과목이 모두 배치된 시간표 - 수행 과정: 과목을 하나씩 빈 시간에 넣기

    ✅ 점검하기¶

    1. 다음 중 '초기 상태'에 해당하는 것은?

    냉장고에 재료가 있고 요리를 시작하려는 상황에서: - (가) 재료들이 냉장고에 있는 상태 - (나) 완성된 요리가 식탁에 있는 상태 - (다) 재료를 손질하는 과정

    정답 확인 **(가)** — 아직 아무 행동도 하지 않은 처음 상태가 초기 상태입니다.

    2. 컴퓨팅으로 해결 가능한 문제의 3요소를 모두 쓰세요.

    정답 확인 **초기 상태, 목표 상태, 수행 과정**

    3. "10개의 숫자 중 가장 큰 수를 찾아라"라는 문제에서 목표 상태는 무엇인가요?

    정답 확인 **10개의 숫자 중 가장 큰 수가 무엇인지 알게 된 상태** (예: "가장 큰 수는 97입니다")
