    3차시·4차시 통합 정리 — 정렬 알고리즘 총정리¶

    🎯 이 장에서 배우는 것¶

    • 버블 정렬, 삽입 정렬, 퀵 정렬의 원리와 특징을 비교하여 설명할 수 있다
    • 빅오 표기법을 활용하여 세 알고리즘의 효율성을 비교할 수 있다
    • 정렬이 탐색 알고리즘의 중요한 전제 조건임을 설명할 수 있다

    📚 핵심 개념¶

    개념 1: 세 가지 정렬 알고리즘 비교¶

    지금까지 배운 정렬 알고리즘을 한눈에 정리해봅시다.

    버블 정렬 (Bubble Sort) - 비유: 탄산음료의 거품이 위로 올라가듯, 큰 값이 뒤로 이동 - 원리: 인접한 두 요소를 비교하여 순서가 잘못되면 교환 - 특징: 단순하지만 느림, 항상 O(n²)

    삽입 정렬 (Insertion Sort) - 비유: 카드 게임에서 손에 든 카드를 정렬하는 방식 - 원리: 정렬된 영역에 새 요소를 올바른 위치에 삽입 - 특징: 거의 정렬된 데이터에서 빠름, 최선 O(n)

    퀵 정렬 (Quick Sort) - 비유: 키를 기준으로 줄 세우기 (기준보다 작으면 왼쪽, 크면 오른쪽) - 원리: 피벗을 기준으로 분할 후 재귀적으로 정렬 - 특징: 분할 정복 전략, 피벗 선택이 성능 좌우

    개념 2: 빅오 표기법으로 효율성 비교¶

    빅오 표기법은 데이터 개수(n)가 늘어날 때 수행 시간이 어떻게 변하는지 나타냅니다.

    각 알고리즘의 시간 복잡도

    • O(n²): 버블 정렬, 삽입 정렬(최악)
    • 데이터가 10개 → 100번 연산

    • 데이터가 100개 → 10,000번 연산

    • O(n): 삽입 정렬(최선, 거의 정렬된 경우)

    • 데이터가 10개 → 10번 연산

    • 데이터가 100개 → 100번 연산

    • 퀵 정렬: 피벗 선택에 따라 성능 변동

    • 좋은 피벗: 매우 빠름
    • 나쁜 피벗: O(n²)까지 느려질 수 있음

    개념 3: 정렬과 탐색의 연결¶

    💡 생각해보기: 1000권의 책에서 특정 책을 찾아야 한다면?

    정렬되지 않은 책장: 처음부터 끝까지 한 권씩 확인 (순차 탐색)

    정렬된 책장: 중간을 펼쳐 범위를 절반씩 좁힘 (이진 탐색)

    정렬은 탐색의 효율성을 높이는 전제 조건입니다. 다음 파트에서 배울 이진 탐색은 반드시 정렬된 데이터에서만 사용할 수 있습니다.

    🔨 따라하기: 세 가지 정렬 비교 실습¶

    6개의 데이터 [29, 10, 14, 37, 13, 25]를 세 가지 방법으로 정렬하며 교환 횟수를 비교해봅시다.

    Step 1: 버블 정렬 구현¶

    # 버블 정렬: 인접한 요소 비교 후 교환
data = [29, 10, 14, 37, 13, 25]
count = 0  # 교환 횟수

for i in range(len(data) - 1):
    for j in range(len(data) - 1 - i):
        if data[j] > data[j + 1]:
            data[j], data[j + 1] = data[j + 1], data[j]
            count += 1

print(f"버블 정렬 결과: {data}")
print(f"교환 횟수: {count}회")

    실행 결과: 

    버블 정렬 결과: [10, 13, 14, 25, 29, 37]
교환 횟수: 8회

    Step 2: 삽입 정렬 구현¶

    # 삽입 정렬: 정렬된 영역에 올바른 위치 삽입
data = [29, 10, 14, 37, 13, 25]
count = 0  # 이동 횟수

for i in range(1, len(data)):
    key = data[i]
    j = i - 1
    while j >= 0 and data[j] > key:
        data[j + 1] = data[j]
        j -= 1
        count += 1
    data[j + 1] = key

print(f"삽입 정렬 결과: {data}")
print(f"이동 횟수: {count}회")

    실행 결과: 

    삽입 정렬 결과: [10, 13, 14, 25, 29, 37]
이동 횟수: 9회

    Step 3: 퀵 정렬 구현¶

    # 퀵 정렬: 피벗 기준 분할 후 재귀 정렬
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]  # 첫 번째 요소를 피벗으로
    left = [x for x in arr[1:] if x < pivot]
    right = [x for x in arr[1:] if x >= pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)

data = [29, 10, 14, 37, 13, 25]
result = quick_sort(data)
print(f"퀵 정렬 결과: {result}")

    실행 결과: 

    퀵 정렬 결과: [10, 13, 14, 25, 29, 37]

    📝 전체 코드: 알고리즘 비교 프로그램¶

    # 정렬 알고리즘 비교 프로그램
def bubble_sort(arr):
    data = arr.copy()
    count = 0
    for i in range(len(data) - 1):
        for j in range(len(data) - 1 - i):
            if data[j] > data[j + 1]:
                data[j], data[j + 1] = data[j + 1], data[j]
                count += 1
    return data, count

def insertion_sort(arr):
    data = arr.copy()
    count = 0
    for i in range(1, len(data)):
        key = data[i]
        j = i - 1
        while j >= 0 and data[j] > key:
            data[j + 1] = data[j]
            j -= 1
            count += 1
        data[j + 1] = key
    return data, count

def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if x < pivot]
    right = [x for x in arr[1:] if x >= pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)

# 테스트
original = [29, 10, 14, 37, 13, 25]
print(f"원본 데이터: {original}\n")

result1, count1 = bubble_sort(original)
print(f"버블 정렬: {result1} (교환 {count1}회)")

result2, count2 = insertion_sort(original)
print(f"삽입 정렬: {result2} (이동 {count2}회)")

result3 = quick_sort(original)
print(f"퀵 정렬: {result3}")

    ⚠️ 주의할 점¶

    1. 알고리즘 선택은 상황에 따라 달라집니다 - 데이터가 거의 정렬됨 → 삽입 정렬 유리 - 대량의 무작위 데이터 → 퀵 정렬 유리 - 간단한 구현 필요 → 버블 정렬

    2. 이진 탐색 전 정렬 필수 - 정렬되지 않은 데이터에 이진 탐색을 적용하면 잘못된 결과가 나옵니다

    ✅ 점검하기¶

    1. 인접한 두 요소를 비교하며 교환하는 정렬 알고리즘은?

    정답 확인 버블 정렬입니다. 거품이 올라가듯 큰 값이 뒤로 이동합니다.

    2. 거의 정렬된 데이터에서 가장 효율적인 알고리즘은?

    정답 확인 삽입 정렬입니다. 최선의 경우 O(n)으로 매우 빠릅니다.

    3. 이진 탐색을 사용하려면 데이터가 어떤 상태여야 할까요?

    정답 확인 반드시 정렬된 상태여야 합니다. 정렬되지 않으면 중간값 비교가 의미 없습니다.
