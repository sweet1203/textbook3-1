    🌊 재난 속 대피경로 — 모델링으로 구조화하기¶

    Part 2: 문제 분해와 모델링 — 복잡한 문제를 쪼개고 구조화하기

    🎯 이 장에서 배우는 것¶

    • 모델링의 정의를 설명하고, 추상화된 요소들의 관계를 시각적으로 표현할 수 있다
    • 재난 대피 상황에서 그래프 모델을 활용하여 문제를 구조화할 수 있다
    • 문제 분해 → 추상화 → 모델링의 전체 흐름을 하나의 사례로 완성할 수 있다
    • 상황에 적합한 모델링 방법(그래프, 표, 그림 등)을 선택할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    갑자기 홍수가 발생했습니다. 마을 주민 100명이 안전 지대로 이동해야 합니다. 어떤 길은 물에 잠겼고, 어떤 다리는 무너졌습니다.

    "어떤 길로 가야 가장 빠르고 안전하게 대피할 수 있을까요?"

    이 질문에 답하려면 복잡한 현실을 단순하고 명확한 형태로 바꿔야 합니다. 실제 지도를 들고 뛰어다닐 수 없으니까요.

    모델링은 바로 이런 상황에서 빛을 발합니다. 복잡한 현실 세계를 점과 선, 표, 수식 같은 단순한 형태로 바꾸면:

    • 🚀 컴퓨터가 최적의 경로를 계산할 수 있습니다
    • 👀 사람이 한눈에 상황을 파악할 수 있습니다
    • 🔄 조건이 바뀌어도 빠르게 대응할 수 있습니다

    내비게이션 앱이 "5분 후 도착"이라고 알려줄 수 있는 것도, 복잡한 도로망을 그래프 모델로 표현했기 때문입니다.

    📚 핵심 개념¶

    개념 1: 모델링이란?¶

    🎭 비유로 시작하기

    여러분이 친구에게 학교 가는 길을 설명한다고 생각해보세요.

    실제 풍경을 전부 설명하면 이렇습니다:

    "우리 집 앞 파란 대문을 나서서 왼쪽으로 가면 편의점이 있고, 그 옆에 꽃집이 있는데 거기서 우회전하면..."

    하지만 간단한 약도를 그리면?

    graph LR A[우리 집] -->|도보 3분| B[편의점] B -->|도보 2분| C[사거리] C -->|도보 5분| D[학교]

    복잡한 현실이 핵심만 남은 단순한 그림이 되었습니다. 이것이 바로 모델링입니다!

    📖 정확한 정의

    모델링(Modeling): 추상화된 핵심 요소들 간의 관계를 구조화하여 이해하기 쉬운 형태(글, 그림, 수식, 표 등)로 표현하는 것

    이전 장에서 배운 추상화가 "무엇이 중요한가?"를 결정하는 것이라면, 모델링은 "그것들이 어떻게 연결되는가?"를 표현하는 것입니다.

    ✅ 예시로 확인

    지하철 노선도를 생각해보세요:

    • 실제 지하철: 복잡한 터널, 다양한 깊이, 구불구불한 선로
    • 노선도 모델: 역(점)과 연결(선)만 표현

    노선도는 실제 지리적 위치나 거리를 정확히 반영하지 않습니다. 하지만 "어떤 역에서 어떤 역으로 갈 수 있는가?"라는 관계는 완벽하게 보여줍니다.

    개념 2: 그래프 모델¶

    🕸️ 비유로 시작하기

    SNS 친구 관계를 생각해보세요. "민수는 지영이와 친구이고, 지영이는 수빈이와 친구이다."

    이걸 어떻게 표현할까요?

    graph LR 민수 --- 지영 지영 --- 수빈 민수 --- 수빈

    사람은 점(노드), 친구 관계는 선(엣지)으로 표현됩니다!

    📖 정확한 정의

    그래프(Graph): 점(노드, Node)과 선(엣지, Edge)으로 구성된 모델 - 노드: 대상, 장소, 상태 등을 표현 - 엣지: 노드 간의 관계, 연결, 이동 가능성 등을 표현

    ✅ 재난 대피에 적용하기

    홍수 상황에서 마을 지도를 그래프로 모델링하면:

    • 노드 = 마을, 대피소, 주요 지점
    • 엣지 = 이동 가능한 길
    • 가중치 = 이동 시간 또는 거리
    graph TD A[A마을] -->|10분| B[B마을] A -->|15분| C[C마을] B -->|5분| D[대피소] C -->|20분| D B -->|8분| C

    이제 "A마을에서 대피소까지 가장 빠른 경로는?"이라는 질문에 답할 수 있습니다!

    개념 3: 모델링 방법의 종류¶

    상황에 따라 적합한 모델링 방법이 다릅니다.

    🎨 네 가지 주요 방법

    mindmap root((모델링 방법)) 그림/그래프 관계 시각화 경로 탐색 표 데이터 정리 비교 분석 수식 정확한 계산 예측 글 절차 설명 조건 기술

    각 방법의 특징

    • 그림/그래프: 관계와 연결을 시각적으로 파악할 때 유용

    • 예: 대피경로, 조직도, 네트워크

    • 표: 여러 항목의 속성을 비교할 때 유용

    • 예: 대피소별 수용 인원, 물자 현황

    • 수식: 정확한 계산이나 예측이 필요할 때 유용

    • 예: 이동 시간 = 거리 ÷ 속도

    • 글(의사코드): 절차나 조건을 명확히 기술할 때 유용

    • 예: "만약 다리가 무너졌다면, 우회로를 선택한다"

    개념 4: 문제 분해 → 추상화 → 모델링 흐름¶

    🔗 세 단계의 연결

    flowchart LR A[복잡한 문제] --> B[문제 분해] B --> C[추상화] C --> D[모델링] D --> E[해결 가능한 형태] B -.->|"큰 문제를<br>작은 문제로"| B C -.->|"핵심만<br>추출"| C D -.->|"관계를<br>구조화"| D

    재난 대피 문제에 적용

    • 1단계 - 문제 분해:

    • "안전하게 대피하기" → "경로 파악 + 이동 시간 계산 + 위험 지역 회피"

    • 2단계 - 추상화:

    • 핵심: 출발지, 목적지, 연결된 길, 이동 시간

    • 제거: 건물 색깔, 나무 위치, 날씨 상세 정보

    • 3단계 - 모델링:

    • 장소 → 노드, 길 → 엣지, 시간 → 가중치
    • 그래프로 시각화

    🔨 따라하기: 재난 대피경로 모델링¶

    📋 시나리오¶

    상황: 폭우로 인해 홍수가 발생했습니다.

    • 5개 마을(A, B, C, D, E)이 있습니다
    • 대피소는 E마을에 있습니다
    • 일부 길은 침수되었습니다
    • A마을 주민들이 대피소로 이동해야 합니다

    Step 1: 문제 분해하기¶

    먼저 큰 문제를 작은 문제로 나눕니다.

    [큰 문제] A마을 주민이 E대피소로 안전하게 이동하기

    ↓ 분해

[작은 문제 1] 어떤 길들이 이동 가능한가?
[작은 문제 2] 각 길의 이동 시간은 얼마인가?
[작은 문제 3] 가장 빠른 경로는 무엇인가?

    Step 2: 정보 수집 및 추상화하기¶

    주어진 정보를 정리합니다:

    이동 가능한 길과 시간 - A → B: 10분 - A → C: 25분 (일부 침수, 느림) - B → C: 5분 - B → D: 15분 - C → D: 10분 - C → E: 30분 (침수로 통행 불가 ❌) - D → E: 10분

    핵심 요소 추출 (추상화) - 노드: A, B, C, D, E (마을/대피소) - 엣지: 이동 가능한 길 - 가중치: 이동 시간(분) - 제외: 침수된 C→E 경로

    Step 3: 손으로 그래프 그리기¶

    📝 직접 해보기: 노트에 다음을 따라 그려보세요!

    그리는 순서

    1. 동그라미 5개를 그리고 A, B, C, D, E 라벨 붙이기
    2. 이동 가능한 길을 선으로 연결하기
    3. 각 선 위에 이동 시간 적기
    4. 침수된 길(C→E)은 X 표시

    완성된 그래프

    graph LR A((A)) -->|10분| B((B)) A -->|25분| C((C)) B -->|5분| C B -->|15분| D((D)) C -->|10분| D D -->|10분| E((E 대피소)) C -.-|❌침수| E

    Step 4: 경로 분석하기¶

    A에서 E까지 가능한 경로를 찾아봅시다:

    경로 1: A → B → D → E - 시간: 10 + 15 + 10 = 35분

    경로 2: A → C → D → E
    - 시간: 25 + 10 + 10 = 45분

    경로 3: A → B → C → D → E - 시간: 10 + 5 + 10 + 10 = 35분

    최적 경로: 경로 1 또는 3 (둘 다 35분)

    Step 5: 파이썬으로 구현하기¶

    이제 이 모델을 코드로 옮겨봅시다.

    # 그래프를 딕셔너리로 표현하기
# 형식: {출발지: {도착지: 시간, ...}, ...}

evacuation_map = {
    'A': {'B': 10, 'C': 25},
    'B': {'A': 10, 'C': 5, 'D': 15},
    'C': {'A': 25, 'B': 5, 'D': 10},
    'D': {'B': 15, 'C': 10, 'E': 10},
    'E': {'D': 10}  # 대피소
}

# 특정 마을에서 갈 수 있는 곳 확인하기
def show_connections(village):
    if village in evacuation_map:
        print(f"\n{village}마을에서 갈 수 있는 곳:")
        for dest, time in evacuation_map[village].items():
            print(f"  → {dest}마을: {time}분")
    else:
        print(f"{village}마을 정보가 없습니다.")

# 테스트
show_connections('A')
show_connections('B')

    실행 결과 

    A마을에서 갈 수 있는 곳:
  → B마을: 10분
  → C마을: 25분

B마을에서 갈 수 있는 곳:
  → A마을: 10분
  → C마을: 5분
  → D마을: 15분

    Step 6: 경로 시간 계산하기¶

    # 경로의 총 시간을 계산하는 함수
def calculate_route_time(route):
    """
    route: 마을 목록 (예: ['A', 'B', 'D', 'E'])
    반환: 총 이동 시간
    """
    total_time = 0

    for i in range(len(route) - 1):
        current = route[i]
        next_village = route[i + 1]

        # 연결이 있는지 확인
        if next_village in evacuation_map[current]:
            time = evacuation_map[current][next_village]
            total_time += time
            print(f"{current} → {next_village}: {time}분")
        else:
            print(f"⚠️ {current}에서 {next_village}로 갈 수 없습니다!")
            return -1

    return total_time

# 경로 테스트
print("=== 경로 1 ===")
route1 = ['A', 'B', 'D', 'E']
time1 = calculate_route_time(route1)
print(f"총 시간: {time1}분\n")

print("=== 경로 2 ===")
route2 = ['A', 'C', 'D', 'E']
time2 = calculate_route_time(route2)
print(f"총 시간: {time2}분")

    📝 전체 코드¶

    """
🌊 재난 대피경로 모델링 프로그램
- 마을 간 연결 관계를 그래프로 표현
- 경로별 이동 시간 계산
"""

# 1. 그래프 모델 정의
evacuation_map = {
    'A': {'B': 10, 'C': 25},
    'B': {'A': 10, 'C': 5, 'D': 15},
    'C': {'A': 25, 'B': 5, 'D': 10},
    'D': {'B': 15, 'C': 10, 'E': 10},
    'E': {'D': 10}
}

# 2. 연결 정보 출력 함수
def show_connections(village):
    """특정 마을에서 갈 수 있는 곳을 보여줍니다"""
    if village in evacuation_map:
        print(f"\n📍 {village}마을에서 갈 수 있는 곳:")
        for dest, time in evacuation_map[village].items():
            print(f"  → {dest}마을: {time}분")
    else:
        print(f"❌ {village}마을 정보가 없습니다.")

# 3. 경로 시간 계산 함수
def calculate_route_time(route):
    """경로의 총 이동 시간을 계산합니다"""
    total_time = 0
    path_info = []

    for i in range(len(route) - 1):
        current = route[i]
        next_village = route[i + 1]

        if next_village in evacuation_map.get(current, {}):
            time = evacuation_map[current][next_village]
            total_time += time
            path_info.append(f"{current}→{next_village}({time}분)")
        else:
            return -1, "경로 없음"

    return total_time, " → ".join(path_info)

# 4. 실행
print("🌊 재난 대피경로 분석 시스템")
print("=" * 40)

# 모든 마을 연결 정보 출력
for village in ['A', 'B', 'C', 'D', 'E']:
    show_connections(village)

# 경로 비교
print("\n" + "=" * 40)
print("🚶 A마을 → E대피소 경로 분석")
print("=" * 40)

routes = [
    ['A', 'B', 'D', 'E'],
    ['A', 'C', 'D', 'E'],
    ['A', 'B', 'C', 'D', 'E']
]

for i, route in enumerate(routes, 1):
    time, info = calculate_route_time(route)
    print(f"\n경로 {i}: {' → '.join(route)}")
    print(f"  상세: {info}")
    print(f"  총 시간: {time}분")

    문제 1: 개념 확인¶

    다음 중 모델링에 대한 설명으로 올바른 것은?

    1. 복잡한 현실을 있는 그대로 표현하는 것
    2. 문제를 작은 문제로 나누는 것
    3. 핵심 요소들의 관계를 구조화하여 표현하는 것
    4. 불필요한 정보를 제거하는 것
    정답 확인 **정답: 3번** - 1번은 모델링의 반대입니다 (단순화해야 함) - 2번은 **문제 분해**의 정의입니다 - 4번은 **추상화**의 정의입니다

    문제 2: 적합한 모델링 방법 선택¶

    다음 상황에 가장 적합한 모델링 방법을 고르세요.

    상황: "서울에서 부산까지 KTX, 비행기, 버스의 비용과 소요 시간을 비교하고 싶다"

    1. 그래프
    2. 표
    3. 수식
    4. 그림
    정답 확인 **정답: 2번 (표)** 여러 항목(KTX, 비행기, 버스)의 여러 속성(비용, 시간)을 비교할 때는 **표**가 가장 적합합니다.

    문제 3: 그래프 해석¶

    아래 그래프에서 X에서 Z까지 가장 빠른 경로와 시간은?

    graph LR X((X)) -->|3| Y((Y)) X -->|7| Z((Z)) Y -->|2| Z
    정답 확인 **정답: X → Y → Z, 총 5분** - 직접 경로: X → Z = 7분 - 우회 경로: X → Y → Z = 3 + 2 = 5분 우회하는 것이 더 빠릅니다!
