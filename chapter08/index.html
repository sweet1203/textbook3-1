    ♻️ 재활용 데이터 정리 — 정렬이 왜 필요할까?¶

    Part 3: 정렬 알고리즘 — 데이터를 순서대로 정리하는 방법

    🎯 이 장에서 배우는 것¶

    • 정렬의 정의와 필요성을 실생활 사례를 들어 설명할 수 있다
    • 오름차순과 내림차순의 차이를 구분하고 데이터를 직접 정렬할 수 있다
    • 정렬이 탐색 효율성에 미치는 영향을 설명할 수 있다

    💭 생각해보기¶

    여러분이 재활용 센터에서 일한다고 상상해보세요. 오늘 하루 동안 수거된 1,000개의 폐기물 데이터가 뒤섞여 있습니다.

    "가장 많이 버려진 품목이 뭘까요?"

    플라스틱 127개, 유리 89개, 캔 203개, 종이 581개... 이 데이터가 아무 순서 없이 나열되어 있다면, 어떻게 빨리 찾을 수 있을까요?

    바로 이때 필요한 것이 정렬입니다!

    📚 핵심 개념¶

    개념 1: 정렬(Sorting)이란?¶

    비유로 시작: 정렬은 마치 도서관 사서가 책을 가나다순으로 정리하는 것과 같아요. 책이 아무렇게나 꽂혀 있으면 원하는 책을 찾기 어렵지만, 정리되어 있으면 금방 찾을 수 있죠.

    정확한 정의:

    정렬(Sorting) = 데이터를 특정 기준에 따라 순서대로 재배열하는 작업

    예시로 확인: - 숫자: [5, 2, 8, 1] → [1, 2, 5, 8] - 이름: ['다희', '가영', '나현'] → ['가영', '나현', '다희']

    개념 2: 오름차순과 내림차순¶

    비유로 시작: 계단을 오르면 숫자가 커지고(오름차순), 내려가면 숫자가 작아지는(내림차순) 것을 떠올려보세요.

    정확한 정의: - 오름차순(Ascending): 작은 값 → 큰 값 순서로 정렬 - 내림차순(Descending): 큰 값 → 작은 값 순서로 정렬

    예시로 확인:

    flowchart LR subgraph 원본 A["3, 1, 4, 1, 5"] end subgraph 오름차순 B["1, 1, 3, 4, 5"] end subgraph 내림차순 C["5, 4, 3, 1, 1"] end 원본 --> 오름차순 원본 --> 내림차순

    개념 3: 정렬이 탐색에 미치는 영향¶

    비유로 시작: 전화번호부에서 '김철수'를 찾는다고 생각해보세요. 전화번호부가 가나다순으로 정렬되어 있으면 'ㄱ' 섹션만 보면 되지만, 정렬되어 있지 않다면 처음부터 끝까지 모두 확인해야 합니다.

    핵심 원리: - 정렬되지 않은 데이터: 처음부터 하나씩 확인 (순차 탐색) - 정렬된 데이터: 중간부터 범위를 좁혀가며 탐색 가능 (이진 탐색)

    flowchart TD A[1000개 데이터에서 특정 값 찾기] A --> B{정렬 여부?} B -->|정렬 안됨| C[최대 1000번 비교] B -->|정렬됨| D[최대 10번 비교] C --> E[느림 😓] D --> F[빠름 ⚡]

    🔨 따라하기: 재활용 데이터 정렬 프로그램¶

    재활용 센터의 폐기물 수거량 데이터를 정렬해봅시다!

    Step 1: 재활용 데이터 준비하기¶

    코드: 

    # 재활용 품목별 수거량 (단위: 개)
recycling_data = [127, 89, 203, 581, 45]
items = ["플라스틱", "유리", "캔", "종이", "스티로폼"]

print("=== 원본 데이터 ===")
for i in range(len(items)):
    print(f"{items[i]}: {recycling_data[i]}개")

    실행 결과: 

    === 원본 데이터 ===
플라스틱: 127개
유리: 89개
캔: 203개
종이: 581개
스티로폼: 45개

    Step 2: 파이썬 내장 정렬 사용하기¶

    코드: 

    # 오름차순 정렬
ascending = sorted(recycling_data)
print("오름차순:", ascending)

# 내림차순 정렬
descending = sorted(recycling_data, reverse=True)
print("내림차순:", descending)

    실행 결과: 

    오름차순: [45, 89, 127, 203, 581]
내림차순: [581, 203, 127, 89, 45]

    Step 3: 가장 많이/적게 버려진 품목 찾기¶

    코드: 

    # 품목과 수량을 함께 묶어서 정렬
data_with_items = list(zip(items, recycling_data))
# zip 결과: [("플라스틱", 127), ("유리", 89), ...]

# 수량 기준 내림차순 정렬
sorted_data = sorted(data_with_items, key=lambda x: x[1], reverse=True)

print("=== 수거량 순위 ===")
for rank, (item, count) in enumerate(sorted_data, 1):
    print(f"{rank}위: {item} - {count}개")

    실행 결과: 

    === 수거량 순위 ===
1위: 종이 - 581개
2위: 캔 - 203개
3위: 플라스틱 - 127개
4위: 유리 - 89개
5위: 스티로폼 - 45개

    Step 4: 정렬 전후 탐색 시간 비교 체험¶

    코드: 

    import time

# 큰 데이터 생성 (1부터 10000까지 섞인 숫자)
import random
big_data = list(range(1, 10001))
random.shuffle(big_data)  # 무작위로 섞기

target = 7777  # 찾을 숫자

# 정렬 안 된 상태에서 탐색
count_unsorted = 0
for num in big_data:
    count_unsorted += 1
    if num == target:
        break
print(f"정렬 전 탐색: {count_unsorted}번 비교")

# 정렬 후 이진 탐색
sorted_data = sorted(big_data)
count_sorted = 0
low, high = 0, len(sorted_data) - 1
while low <= high:
    count_sorted += 1
    mid = (low + high) // 2
    if sorted_data[mid] == target:
        break
    elif sorted_data[mid] < target:
        low = mid + 1
    else:
        high = mid - 1
print(f"정렬 후 탐색: {count_sorted}번 비교")

    실행 결과 (예시): 

    정렬 전 탐색: 4523번 비교
정렬 후 탐색: 14번 비교

    📝 전체 코드¶

    # 재활용 데이터 정렬 프로그램

# 1. 데이터 준비
recycling_data = [127, 89, 203, 581, 45]
items = ["플라스틱", "유리", "캔", "종이", "스티로폼"]

# 2. 원본 출력
print("=== 원본 데이터 ===")
for i in range(len(items)):
    print(f"{items[i]}: {recycling_data[i]}개")

# 3. 오름차순/내림차순 정렬
print("\n오름차순:", sorted(recycling_data))
print("내림차순:", sorted(recycling_data, reverse=True))

# 4. 품목별 순위 출력
data_with_items = list(zip(items, recycling_data))
sorted_data = sorted(data_with_items, key=lambda x: x[1], reverse=True)

print("\n=== 수거량 순위 ===")
for rank, (item, count) in enumerate(sorted_data, 1):
    print(f"{rank}위: {item} - {count}개")

    ⚠️ 주의할 점¶

    1. sort()와 sorted()의 차이 - 리스트.sort(): 원본 리스트 자체를 변경 - sorted(리스트): 새로운 정렬된 리스트를 반환 (원본 유지)

    data = [3, 1, 2]
sorted(data)      # data는 그대로 [3, 1, 2]
data.sort()       # data가 [1, 2, 3]으로 변경됨

    2. 정렬 기준이 명확해야 함 - 숫자는 크기 순서가 명확하지만, 복합 데이터(예: 학생 정보)는 어떤 기준(이름? 점수?)으로 정렬할지 지정해야 합니다.

    ✅ 점검하기¶

    1. 정렬의 정의를 한 문장으로 설명하세요.

    정답 확인 정렬은 **데이터를 특정 기준에 따라 순서대로 재배열하는 작업**입니다.

    2. [10, 3, 7, 1]을 내림차순으로 정렬하면?

    정답 확인 `[10, 7, 3, 1]` — 큰 값에서 작은 값 순서로 정렬

    3. O/X 퀴즈: "정렬된 데이터에서는 원하는 값을 더 빨리 찾을 수 있다."

    정답 확인 **O** — 정렬된 데이터에서는 이진 탐색을 사용할 수 있어, 탐색 범위를 절반씩 줄여가며 빠르게 찾을 수 있습니다.

    🚀 도전 문제¶

    손 활동: 숫자 카드 정렬하기

    종이에 8, 3, 5, 1, 9를 적고 직접 손으로 정렬해보세요.

    1. 오름차순으로 정렬: ___, ___, ___, ___, ___
    2. 내림차순으로 정렬: ___, ___, ___, ___, ___
    3. 정렬하면서 카드를 몇 번 비교했나요?
    정답 확인 1. 오름차순: `1, 3, 5, 8, 9` 2. 내림차순: `9, 8, 5, 3, 1` 3. 비교 횟수는 정렬 방법에 따라 다릅니다. 다음 장에서 배울 버블 정렬로는 약 10번 정도 비교하게 됩니다!

    📌 핵심 개념 정리¶

    정렬(Sorting) - 데이터를 특정 기준에 따라 순서대로 재배열하는 작업

    오름차순 vs 내림차순 - 오름차순: 작은 값 → 큰 값 - 내림차순: 큰 값 → 작은 값

    정렬의 필요성 - 데이터 파악이 쉬워짐 (최댓값, 최솟값 바로 확인) - 탐색 효율성이 크게 향상됨 (이진 탐색 가능)
