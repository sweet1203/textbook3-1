    🚑 핵심만 남기기 — 추상화의 힘¶

    Part 2: 문제 분해와 모델링 — 복잡한 문제를 쪼개고 구조화하기

    🎯 이 장에서 배우는 것¶

    • 추상화의 정의를 설명하고, 불필요한 요소와 핵심 요소를 구분할 수 있다
    • 응급의료 환자 분류 상황에서 추상화를 적용하여 핵심 정보만 추출할 수 있다
    • 추상화가 문제 해결의 효율성을 어떻게 높이는지 사례를 들어 설명할 수 있다
    • 일상생활의 문제에 추상화를 적용할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    아래 두 이미지를 비교해 보세요. - 실제 서울 지도: 구불구불한 도로, 건물, 산, 강의 정확한 위치 - 지하철 노선도: 직선과 원으로 단순화된 역과 노선

    질문: 왜 지하철 노선도는 실제 거리와 방향을 무시했을까요?

    지하철을 탈 때 우리에게 필요한 정보는 무엇일까요? "2호선을 타고 3정거장 가서 환승"처럼 어떤 역에서 어떤 노선으로 갈아타는지가 중요합니다. 역 사이의 실제 거리나 구불구불한 선로 모양은 필요 없죠.

    이것이 바로 추상화(Abstraction)입니다. 복잡한 현실에서 목적에 맞는 핵심만 남기고 나머지를 과감히 버리는 것입니다.

    flowchart LR A[복잡한 현실 세계] --> B{추상화} B --> C[핵심만 남긴 단순한 모델] style B fill:#FFE4B5,stroke:#FF8C00,stroke-width:2px

    프로그래밍에서 추상화는 필수 기술입니다. 왜냐하면:

    • 컴퓨터는 모든 것을 처리할 수 없습니다 — 꼭 필요한 정보만 다뤄야 효율적입니다
    • 복잡한 문제를 단순하게 만들어야 해결책이 보입니다
    • 핵심을 파악해야 올바른 알고리즘을 설계할 수 있습니다

    📚 핵심 개념¶

    개념 1: 추상화란 무엇인가?¶

    비유로 시작하기 🎨¶

    여러분이 친구에게 "우리 학교 가는 길"을 설명한다고 해보세요.

    방법 A (너무 상세함):

    "집 현관문을 열고 왼발부터 내딛어. 보도블록 색깔은 회색이야. 3번째 가로수 옆에서 오른쪽으로 15도 방향 전환하고, 142걸음 직진해..."

    방법 B (핵심만):

    "정문 나와서 오른쪽으로 쭉 가다가 사거리에서 좌회전하면 돼."

    방법 B가 훨씬 이해하기 쉽죠? 이게 추상화입니다!

    정확한 정의 📖¶

    추상화(Abstraction)

    복잡한 문제나 대상에서 불필요한 세부 사항을 제거하고, 문제 해결에 반드시 필요한 핵심 요소만 추출하는 과정

    추상화의 핵심 질문: - "이 문제를 해결하려면 꼭 알아야 할 것은 무엇인가?" - "없어도 되는 정보는 무엇인가?"

    예시로 확인하기 ✅¶

    예시: 카카오톡 프로필

    실제 사람에게는 수많은 정보가 있습니다: - 키, 몸무게, 혈액형, 좋아하는 음식, 오늘 입은 옷 색깔, 발 사이즈...

    하지만 카카오톡 프로필에는? - 프로필 사진 (누구인지 식별) - 이름 (누구인지 확인) - 상태 메시지 (현재 상황)

    → 메신저의 목적(상대방 식별, 소통)에 맞는 핵심 정보만 남긴 것입니다.

    개념 2: 핵심 요소 vs 불필요한 요소 구분하기¶

    추상화에서 가장 중요한 능력은 "무엇을 남기고 무엇을 버릴지" 판단하는 것입니다.

    flowchart TB subgraph 판단기준["🎯 핵심 요소 판단 기준"] Q1["문제 해결에 직접 영향을 주는가?"] Q2["이 정보 없이 답을 구할 수 있는가?"] Q3["목적 달성에 필수적인가?"] end Q1 -->|Yes| KEEP["✅ 핵심 요소로 유지"] Q2 -->|No| KEEP Q3 -->|Yes| KEEP Q1 -->|No| DROP["❌ 불필요한 요소로 제거"] Q2 -->|Yes| DROP Q3 -->|No| DROP

    연습 문제: 온라인 쇼핑몰에서 상품 검색

    사용자가 "운동화"를 검색했을 때, 검색 시스템이 고려해야 할 정보는?

    • ✅ 핵심 요소: 상품명, 카테고리, 가격, 재고 여부
    • ❌ 불필요한 요소: 상품 등록 직원 이름, 창고 위치, 배송 박스 크기

    개념 3: 응급의료에서의 추상화 — 환자 분류(Triage)¶

    알아보기 📋

    트리아지(Triage)란 대형 재난이나 응급 상황에서 제한된 의료 자원으로 최대한 많은 생명을 구하기 위해 환자를 분류하는 체계입니다.

    상황 설정¶

    대형 교통사고 현장입니다. 환자 50명이 동시에 발생했고, 구급차는 5대뿐입니다. 의료진은 누구를 먼저 치료할지 빠르게 결정해야 합니다.

    각 환자에게는 수많은 정보가 있습니다: - 이름, 나이, 직업, 가족 관계 - 키, 몸무게, 평소 건강 상태 - 오늘 뭘 먹었는지, 어디로 가던 중이었는지 - 체온, 호흡, 맥박, 의식 수준, 출혈량, 외상 부위

    추상화 적용하기¶

    의료진이 5초 안에 판단하려면 어떤 정보만 봐야 할까요?

    flowchart LR subgraph 제거["❌ 불필요한 요소"] A1["이름"] A2["직업"] A3["가족관계"] A4["이동 목적"] end subgraph 핵심["✅ 핵심 요소"] B1["의식 수준"] B2["호흡 여부"] B3["출혈량"] B4["맥박"] end 핵심 --> C["빠른 분류 가능!"]

    핵심 요소 3가지로 단순화:

    1. 의식 수준: 반응이 있는가? (있다/없다)
    2. 호흡: 스스로 숨을 쉬는가? (정상/비정상/없음)
    3. 출혈: 대량 출혈이 있는가? (있다/없다)

    추상화된 환자 분류 기준¶

    flowchart TD START["환자 발견"] --> Q1{"호흡이 있는가?"} Q1 -->|없음| RED["🔴 긴급<br/>즉시 치료"] Q1 -->|있음| Q2{"대량 출혈?"} Q2 -->|있음| RED Q2 -->|없음| Q3{"의식이 있는가?"} Q3 -->|없음| YELLOW["🟡 응급<br/>1시간 내 치료"] Q3 -->|있음| GREEN["🟢 비응급<br/>대기 가능"]

    정리하기 📌

    추상화를 통해 복잡한 환자 상태를 3가지 질문으로 단순화했습니다. 이제 의료진은 50명의 환자를 빠르게 분류하고 제한된 자원을 효율적으로 배분할 수 있습니다.

    개념 4: 추상화의 힘 — 효율성 향상¶

    추상화가 문제 해결에서 얼마나 효율성을 높이는지 비교해 봅시다.

    사례 1: 내비게이션 시스템

    • 추상화 전: 모든 건물, 나무, 신호등, 보행자까지 고려
    • 추상화 후: 도로, 교차로, 거리, 소요시간만 고려

    → 결과: 수십만 개의 데이터 대신 수천 개만 처리하여 1초 만에 경로 계산

    사례 2: 게임 캐릭터

    RPG 게임에서 캐릭터를 만들 때 실제 사람의 모든 특성을 넣으면? - 소화 능력, 시력, 청력, 발톱 길이, 머리카락 수...

    → 게임에 필요한 것만 남기면: - HP(체력), MP(마나), 공격력, 방어력, 속도

    # 추상화된 게임 캐릭터
class Character:
    def __init__(self, name):
        self.name = name      # 이름
        self.hp = 100         # 체력
        self.mp = 50          # 마나
        self.attack = 10      # 공격력
        self.defense = 5      # 방어력

    핵심만 남기니 코드도 단순하고, 계산도 빠르고, 이해도 쉽습니다!

    🔨 따라하기: 학교 통학 경로 추상화¶

    직접 추상화를 연습해 봅시다. 여러분의 집에서 학교까지 가는 경로를 추상화해 보겠습니다.

    Step 1: 원래 정보 나열하기¶

    먼저 통학할 때 경험하는 모든 것을 적어봅니다.

    집을 나섬 → 엘리베이터 탐 → 아파트 정문 통과 → 
편의점 앞 지나감 → 신호등에서 대기 → 횡단보도 건넘 → 
버스정류장 도착 → 버스 기다림 → 102번 버스 탑승 → 
창밖 구경 → 학교앞 정류장 하차 → 학교 정문 통과 → 
교실 도착

    Step 2: 목적 정의하기¶

    질문: "이 정보를 왜 정리하는가?"

    목적: 늦잠 잤을 때 가장 빠른 경로를 찾기 위해

    Step 3: 핵심 요소 추출하기¶

    목적(빠른 경로)에 맞춰 핵심만 남깁니다.

    핵심 요소: - 이동 수단 (도보, 버스, 지하철) - 소요 시간 - 환승 지점

    제거할 요소: - 편의점, 창밖 풍경 (경로와 무관) - 엘리베이터 (시간 절약 불가) - 신호등 색깔 (제어 불가)

    📝 전체 코드¶

    환자 분류 시스템을 추상화하여 파이썬으로 구현한 전체 코드입니다.

    # 🚑 응급 환자 분류 시스템 (추상화 적용)
# 핵심 요소: 호흡, 출혈, 의식

def classify_patient(breathing, bleeding, conscious):
    """
    환자 상태를 추상화된 기준으로 분류합니다.

    Parameters:
        breathing (bool): 호흡 여부 (True: 정상, False: 비정상/없음)
        bleeding (bool): 대량 출혈 여부 (True: 있음, False: 없음)
        conscious (bool): 의식 여부 (True: 있음, False: 없음)

    Returns:
        str: 분류 결과 (긴급/응급/비응급)
    """

    # 호흡이 없거나 대량 출혈이면 긴급
    if not breathing or bleeding:
        return "🔴 긴급 - 즉시 치료 필요"

    # 호흡은 있지만 의식이 없으면 응급
    if not conscious:
        return "🟡 응급 - 1시간 내 치료"

    # 호흡, 의식 모두 정상이고 출혈 없으면 비응급
    return "🟢 비응급 - 대기 가능"


# 테스트: 여러 환자 분류하기
print("=== 환자 분류 결과 ===\n")

# 환자 1: 호흡 정상, 출혈 없음, 의식 있음
patient1 = classify_patient(breathing=True, bleeding=False, conscious=True)
print(f"환자 1: {patient1}")

# 환자 2: 호흡 없음
patient2 = classify_patient(breathing=False, bleeding=False, conscious=False)
print(f"환자 2: {patient2}")

# 환자 3: 호흡 정상, 대량 출혈
patient3 = classify_patient(breathing=True, bleeding=True, conscious=True)
print(f"환자 3: {patient3}")

# 환자 4: 호흡 정상, 출혈 없음, 의식 없음
patient4 = classify_patient(breathing=True, bleeding=False, conscious=False)
print(f"환자 4: {patient4}")

    ⚠️ 자주 하는 실수¶

    실수 1: 너무 많이 추상화하기 ❌¶

    # 잘못된 예: 핵심 정보까지 제거
def classify_patient_wrong(is_alive):
    if is_alive:
        return "치료"
    else:
        return "치료 불필요"

    문제점: "살아있다/죽었다"만으로는 치료 우선순위를 정할 수 없습니다!

    올바른 접근: 목적(우선순위 결정)에 필요한 최소한의 정보는 유지해야 합니다.

    실수 2: 목적을 고려하지 않고 추상화하기 ❌¶

    잘못된 예: 학교 통학 경로를 추상화할 때 "가장 빠른 경로"가 목적인데, 풍경이 좋은 구간을 핵심 요소로 선정

    올바른 접근: 항상 "왜 이 문제를 해결하는가?"를 먼저 명확히 하세요.

    실수 3: 상황에 따라 핵심이 바뀔 수 있음을 무시하기 ❌¶

    예시: 같은 "환자 정보"라도...

    • 응급 분류 시: 호흡, 출혈, 의식이 핵심
    • 보험 청구 시: 이름, 주민번호, 진단명이 핵심
    • 역학 조사 시: 나이, 지역, 접촉자가 핵심

    기억하세요 💡

    추상화의 핵심 요소는 목적에 따라 달라집니다. 정답이 하나가 아닙니다!

    ✅ 스스로 점검하기¶

    문제 1: O/X 퀴즈¶

    다음 설명이 맞으면 O, 틀리면 X를 선택하세요.

    1. 추상화는 모든 정보를 최대한 자세히 담는 것이다. ( )
    2. 지하철 노선도는 추상화의 좋은 예시이다. ( )
    3. 추상화에서 핵심 요소는 문제의 목적과 관계없이 항상 동일하다. ( )
    4. 추상화를 하면 문제 해결의 효율성이 높아진다. ( )
    정답 확인 1. **X** - 추상화는 불필요한 것을 제거하고 핵심만 남기는 것입니다. 2. **O** - 실제 지리 정보 대신 역과 노선의 연결만 표현합니다. 3. **X** - 핵심 요소는 목적에 따라 달라집니다. 4. **O** - 처리할 정보가 줄어들어 효율적입니다.

    • 음식점 인테리어 스타일
    • 현재 도로 교통 상황
    • 음식점 사장님의 취미
    • 음식 조리 예상 시간
    • 배달원의 혈액형
